# 全局复盘 · 割裂点专项（流程 × 节点）

> 2026-08-18 · 对设计方案 v4.2 的第二次全局复盘。上轮猎**缺口**（少什么功能），本轮猎**割裂**（流程流经节点/场所/surface/时间边界时断开、人被迫当胶水的缝）。
> 方法：三路独立——模型层六大环路断点追踪（委派/目标/会议/工件/人类承诺/注意力）+ 两组剧本重走（剧本1/4/6、剧本2/3/5）。26 条割裂点，收敛为**四大结构性共因 + 对冻结框架自身的两条修正案**。

---

## 〇、总诊断

> **v1 缝合的是空间上的割裂（IM 与 agent 两个界面，本是一物）；本轮发现的是时间上的割裂（对象的出生与余生）。** v4 给图配齐了名词（居民）和出生证（不可回填的出生边），但对象出生之后不会呼吸：回执回不来、状态不回写、提醒不可应答、动词只配给操作者一个角色。人是所有回程的泵——每条缝都在收注意力税（人当胶水）、信任税（状态陈旧→张总拿死链接讲错数）、复利税（蒸馏落错轴）。

## 一、四大结构性共因（三路独立收敛）

### 共因 A：回程半边缺失——"图只记出生边，不记回流边"（最大共因，双组 top-1 撞车）

不可回填裁决刀被**不对称地**使用了：出生事件（登记、挂接、血缘、蒸馏来源）全部入了 P1 数据位，而环路闭合依赖的全是**逆向边**——回执、凭据、状态回写、记忆注入、冲突对撞。按设计自己的刀法，"张锐在电梯里说'明天给'"这个回执时刻、"哪个会话消费了哪条口径"这个注入时刻，同样**发生即逝、不记即永久丢失**。

| # | 断点 | 剧本证据 | 冻结判定 |
|---|---|---|---|
| 1 | 人类承诺回执 → 状态（被等待者无任何可应答对象） | 剧本4 周一挨个私聊问进度"像过去十年一样"；剧本3 老周口头回复靠陈静转告 | 冻结内过渡：群内自然语言回执 → agent 提议状态变更（ack 公示可纠同款）；定向询问卡片形态过采纳门 |
| 2 | 外部实体回执 → 图（代发不留痕、回执无入口） | 剧本2 三次复制话术进微信，图不知道发没发 | 冻结内：「已代发」「回执回填」两个登记动词 |
| 3 | 云之家审批单凭据 → 图（两条审批线互盲） | 剧本2 截图喂 agent；剧本3 每天人肉轮询审批应用 | 冻结内：等待对象挂审批单链接 + 凭据人工回填；API 双链互见押基建门 |
| 4 | **记忆注入镜像边**（memory→消费会话不记录） | 剧本1 罗总改口径，逐话题补话漏一个，评审会上才发现 | **P1 数据位**：C6 只记 turn→记忆的出生向，注入向同为不可回填——清单漏了镜像 |

## 二、对冻结框架自身的两条修正案

1. **不可回填清单的镜像扩展**：P1 数据位从"六类出生边"扩为"出生边 + 回流边"——回执登记（人类/外部/审批凭据）、记忆注入边、状态变化时刻、冲突对撞时刻。依据是裁决刀自身的一致性，不是新原则。
2. **证据门补"环路完整性检验"**（剧本2/3/5 组 top-3 独立发现）：冻结按**机制**切阶段门，而割裂按**环路**发生——环路两端落进不同阶段时，人当胶水的时长 = 阶段差；更危险的是**污染证据门信号**（没人挂接 ≠ 不需要挂接，是没有入口）。新规则：**每押后一个视图/通道，必须给留在 P1 的对象配一个最小 IM 习语的进/出口**；P1 降级形态必须明标（如借身期催收 = agent 拟稿 + 操作者亲发），不留给实现者即兴。

## 三、冻结判定汇总

26 条中 **21 条冻结内可修**——绝大多数是"把两个既有件接上"（投影/动词/一条消息/原则执行欠账），不需要新居民、不需要新原则。过门项仅 5 处：纪要摄取（infra 门）、回执自动 adapter（基建门，自然语言回执为冻结内过渡）、定向询问卡片形态（采纳门）、拒收学习（样本门）、对象枢纽完整视图（P4 既定）。

**这本身是模型健康的证据：缝全在肉里（连接组织），不在骨头上（节点与原则）。** 图有了名词和出生证，还缺的是呼吸——回程、应答、按节点泛化的动词。
