# 工作台重构 · 实施记录

> 规格见 [工作台界面重设计.md](./工作台界面重设计.md) v1.1，原型见 [workbench-redesign.html](./workbench-redesign.html)。
> 本文件只记录**怎么落地、落到哪了**，不重复设计理由。
> 每完成一个阶段做五件事：
> 1. 跑 `pnpm vitest run next/surface next/cards`
> 2. 跑 typecheck
> 3. 跑 `pnpm --filter "@yzj-next/*" --sort build`
> 4. 在 3090 上实测，浅色、深色各截一次图
> 5. 落一个 commit 到 main

## 基线（2026-10-21）

- 测试：surface + cards 共 485 个，全绿。
- 样式：CSS 模块里有约 370 处写死的颜色，字号 18 档（10.5px 出现 101 次）。
- 未定义的变量：`--line`、`--ink-soft`、`--yzj-warn`、`--yzj-surface-2`，以及 cards 包里的 `--dsh-color-*`。
- 宿主的暗色挂在 `body[data-ds-dark-theme]` 上。别名 token `--dsw-alias-*` 由宿主的 theme presenter 以内联变量的形式写到 body 上。

## 进度日志

- **P0**（2026-10-21）：
  - **token**：`tokens.module.css` 重写。中性色接宿主的别名 token，墨 3 自定为 `#697180` / `#8A909B`。
  - **成对 solid**：填色按钮配成对的 solid token，如 `--yzj-solid` / `--yzj-on-solid`、`--yzj-pub-solid` / `--yzj-on-color`。这样暗色下白字压在浅蓝上的情况不会出现。
  - **迁移**：19 个 CSS 模块由脚本迁移，颜色按「属性 × 色相」归到语义 token；紫色不属于听众也不属于异常，归回中性色。字号 18 档收成 6 档，圆角收成 4 档。
  - **头像**：头像色改为 `--yzj-av-*`，agent 头像改为 `--yzj-agent` 渐变。
  - **cards 包**：卡坐在宿主的工具座位里，够不着工作台的 `.tokens`，所以给它单独一份 `tokens.module.css`，直接读宿主的别名 token。
  - **棘轮**：新增 `tests/style-ratchet.spec.ts`，共 6 条断言。做过变异检查，故意写错能抓到。
  - **实测**：3090 浅色、深色截图正常。看板、话题流、右栏在暗色下跟着宿主走。

- **P2**（2026-10-21）：
  - **服务端**：`AnswerableDemand` 加了家族自报的 `verb`（默认 `MODE_VERB`；中断的任务是「继续」，中断的确认是「重试」，冲突是「定」）。收件箱加了 `needs[]` 和 `running[]`。
    - `needs[]` 只收阻塞层；每条带谁在等（人执行的交付写那个人，其余写 agent）、开口问的时刻、期限原话。
    - 排序规则：36 小时内到期的排前；其余按等得久的排前。
  - **左栏**：重写，分「要你 / 运行中 / 承诺 / 云之家 / 本地」五段。
    - 一行只亮一个信号。
    - 运行中的活 6 分钟没动静就把转圈变成琥珀色。
    - 未接入的群和会话收成一行，展开后可以按名字找。
    - 自聊行改叫「我 · 审批通道」。
  - **决断条 → 浮动指针**：卡在视野里时不出现；滚走了才浮出来，标明方向，并写「还有 N 件」。旧的条尾租约入口去掉，挪到 P3 的卡上去做规矩提议。
  - **撤回窗的公共状态**：`store.answering`。左栏和指针都读它，撤回窗里的回答立刻不再算「要你」。
  - **公共件**：`icons.tsx`（一套线性图标和 AgentFace）、`words.ts`（`AGENT`，测试保证它等于 `SIGNATURE_AGENT`）、`span` / `waitLine`、`plainError`。
  - **其他**：`.tokens` 下统一 `box-sizing: border-box`。
  - **测试**：新增 `needs.spec.tsx`，共 12 例，覆盖服务端投影、公共说法，以及左栏的逐条、落点、N 键、输入框里不误触、撤回窗。
  - **实测**：3090 上真实数据渲染出 5 条「要你」，抓到一件真卡住的活（「4 小时没进展」）。点一条能落在卡上。指针浮出时标明方向、写「还有 N 件」。浅色、深色都正常。

- **P3**（2026-10-21）：
  - **号只有一张表**：cards 包新增 `numberedActions(type, state)`，桌面卡上的 `[1 确认] [2 取消]` 和云之家卡尾的「回 1 确认 · 2 取消」都从它来。`resolveKeyword` 认「1」「2 价格没定」这类回复（数字后面是原因）。作废、收回、收起这类不可逆或次要的动作标 `secondary`，不占号——按错一个数字不该作废一件事。
  - **出处**：`StreamCard.answered` 从生效的 `answer/recorded` 读，吸收行写「你在云之家里回了「确认」 · 昨天 16:52」或别人的名字。
  - **服务端改动比计划少**：
    - 登记预览直接复用落库用的那个纯函数 `registrationFrom`（挪到 `client/registration.ts`，两边共用），不需要新 RPC。
    - 运行健康度从宿主快照的进展在客户端算（3 分钟没动静就提示），不需要 `lastProgressAt`。
  - **5 秒撤回窗**（`answers.ts`）：回答先在本机暂存，Z 撤回最近一件，页面关闭时立刻落账；窗里别处先答了，本机这份静静丢掉。
  - **卡**：`CardRow` 重写成一个骨架——「● 要你{动词} · 谁在等多久」、标题、为什么、正文、编号按钮、「云之家里回 1 / 2 也行」。提案类走逐条裁决（逐条选、⏎ 一次定下）。交付是文件且没打开过时，多一行「先看 V / 不看，直接通过」。
  - **规矩（律九）**：同一类写入、同一个群连续同意 5 次且没拒过，卡上出现「以后同类不用问 ›」；点了只起草一张租约卡，由人签。服务端 `propose-rule` 会重新核对连续次数。强写永远不提。
  - **规则面板**：「场所合同」改成「云小助在这里的规则」，共六行：接谁的话、每次都问你、写之前问一次、不会做、你签的规矩（范围、谁签的、还剩几天、替你省了几次确认、可收回）、它记着的。工具名和撤销流水收进「看明细」。
  - **一条流**：私下的内容收进纸色带；工作步骤收成一行，可展开，卡住时给「让它重试这一步 / 停下」。消息不加气泡，悬停出动词。云小助的话按 Markdown 排（`Prose.tsx`：只产出 React 元素，链接只认 http(s)）；人的原话照原样显示。
  - **输入框**：`Composer` 统一私下、群里、快问三种口吻。发出前先说清楚：私下点名派活时提醒「X 听不见」，第一次 Enter 先抖一下提示；群里说的话预告「发出后会记下：X 负责 · 什么事 · 原话」。
  - **群视图**：话题卡收成一行，只带一个信号；「看最后几条」悬停时才出现。
  - **cards 包的 toolview 座位**：实测确认 surface 接管了全部会话的 `conversation` 槽，所以这个座位只在 surface 没加载时出现。保留它作为降级出口，不删。
  - **测试**：新增 `cards-p3.spec.tsx`（22 例）和 `prose.spec.tsx`（4 例），`answer-path.spec.ts` 加 1 例（回「1」就是确认）。
  - **实测**（3090，浅色和深色）：
    - 拦下所有写请求后点「重试」：出现「5 秒后生效 · 撤回 Z」，左栏「要你」立刻从 5 减到 4，「下一件」接上；按 Z 卡片回来，等满 5 秒也没有写请求发出。
    - 规则面板六行排版正常。
    - 卡上的去向写出了群名，私聊写成「和代少兵的私聊」，不再是「这个会话所在的群」。

- **P4**（2026-10-21）：
  - **服务端（只读）**：
    - `BoardRowWire.evidence`：从图上推三档——平台记了（回执原子 `seen`）› 有东西（登记之后该话题里有产物边，或交付语里带链接）› 只有一句话。从没动过的行不分档。
    - 新增只读 RPC `commitment-story`：来龙去脉要的原话（从话题消息里按锚找回那一条，找不回就说找不回，不拿整理过的 `what` 冒充）、之后每一笔带证据档、挂在哪、可合并的同伴、可挂的目标。
    - `GoalArtifactWire` 加 `placeName` / `sessionId`：产出从哪个话题来，一跳回去。
  - **承诺**：四个透镜是四种组织轴（全部按目标、欠我的按人、我欠的按对方、🔒我定过的另一屏）。今天条四颗数字都是门，点了落到那一行（折着、在别的透镜里也先调过去）。一行一个信号，悬停换成一两个动词；不对劲的才摊开，正常的收进「其余 N 件正常」。
  - **来龙去脉**：选中一行，右栏摆「怎么来的 · 之后 · 挂在 · 动词」。全站只有这一组修理动词（顺延、转给别人、合并、作废，加挂到目标/不挂了）。归别人管的，只说该去找谁，外加「拆一部分给别人…」（可转包不可脱责）。
  - **右栏开不出来时**：宿主在当前会话为空时不给开抽屉；这时来龙去脉停在本屏右侧（`StoryDock`）。选中一行必须有回应。
  - **共用一行**：`LedgerRow.tsx` / `ledger.ts`——承诺页和目标页同一个信号函数、同一组悬停动词、同一个停靠和 J/K。
  - **目标页**：眉行 · 标题 · 怎么算完成 · 一行事实 · 最多一条提示（目标结束了底下还在跑 › 标准改过 › 云之家很久没对账 › 底下停摆）· [交给…][拆解][评估进度]；要你只放指针；执行默认只摊开不对劲的；产出带出处。删掉三段说明和「闭环自检」，作废目标收进页头 ⋯。
  - **我定过的**：整页纸色；顶上一句「只有你看得到。不进公司的账，随时可以整本带走。」；一族一句话写比值的原料（「同意 33 次，都没被推翻 · 平均 22 天后才去验」），不打分。
  - **会前那一眼、新目标表**：去掉说明腔（「这是合法状态」「就绪度这件事还没被激活」）；新目标表拆到 `DeclareGoal.tsx`。
  - **测试**：新增 `ledger-p4.spec.ts`（9 例）、`goal-p4.spec.ts`（10 例）；`board.spec.ts` 换成「四个透镜 = 四种组织轴」「一行一个信号」两组；`judg.spec.tsx` 加「一族一句话」4 例。
  - **实测**（3090，浅色和深色）：承诺页从多颜色多标签收成一行一信号；点「1 逾期」落到那一行并闪一下；选中一行右侧停靠来龙去脉；目标页、我定过的两屏截图正常。

- **复审与修复 + 3090 实测**（2026-10-21）：
  - **复审**：对着 v1.1 九律和七处已定逐条过代码。P0–P5 都在，缺口在「做了但没做到底」——下面这些补齐。
  - **补齐（判断与卡）**：
    - 逐条定的卡里 J/K 在条之间走，选过的能回去改；没选完写「还有 N 处没选」，不提交。
    - 卡上按钮说清按下去的是什么（`approvalVerbs`）：「确认写入 / 先不写」「确认发出 / 先不发」「确认删除 / 先不删」「确认移交 / 先不移交」，验收是「通过验收」。「为什么问你」也用同一个动词。
    - 登记回执一行：「✓ 记下了：张锐负责 · … · 原话「明天」→ 周四 [改]」。
  - **补齐（账）**：
