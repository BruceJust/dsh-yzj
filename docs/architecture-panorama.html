  • 公网 HTTPS 回调中继载体待对齐云函数 / 轻量服务器 / 内网穿透 + 域名证书；验签在业务侧完成，中继零信任转发
  • 常驻服务化部署待对齐现状 = 桌面机进程必须在线（轮询 + 审批都依赖它活着）；企业级需服务器化与守护
  • LLM API 企业供给待对齐配额 / 密钥管理 / 网关与合规审计——现为个人 provider 配置
  • 外部触达通道（中期）待对齐邮件 / 短信 / 外部日程邀请——组织外实体（客户）的触达 infra
  • 存储与备份图日志 JSONL→sqlite 是本团队内的换底（日志重放，API 不变）；备份策略需运维接手

  • 企业应用注册阶段三appId / secret · team token · resGroupSecret（只读 / 可编辑分级）

边界宣言 · 给对齐会的三句话 ① 我们不向任何团队移交本体：承诺 / 会话 / 听众的真身在会话图，平台对象只当投影、证据源、素材段——对接不产生数据主权纠纷。
② 红色块是企业级化的临界路径：回调中继 → 阶段二整层（秒级触发 / 原生卡 / 待办闭环）；应用 token → 阶段三身份独立；internal 网关化 → 人类承诺闭环。每块都有 fallback，缺了不死但形态降级。
③ 演进不动核心：transport 适配器抽象、卡片渲染通道注册制、updateStrategy 接缝已预留——三阶段演进替换的是通道与身份，图与对象系统一行不改。
