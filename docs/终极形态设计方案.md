## 0. 终极价值

> **组织里由对话承载的真实工作，被可信地完成，且随时间复利。**

| 因子 | 含义 | 由谁承载 |
|---|---|---|
| 任务完成质量 | agent 真的把事做对、做完 | gateway + 工具面 + 模型 |
| 组织信任度 | 群成员敢委派、敢等待、能审计 | 等待可见、归因、透明度工件、审计导出 |
| 注意力节约量 | 人被打断的次数 × 每次的代价 | 注意力路由、审批可达、授权租约、F-read |
| 复利率 | 第六个月比第一天多值多少 | 记忆、工件、**流程结构**、信任积累 |
| **人的复利 = 自知**（v4.25 立，v4.28 定） | 第六个月的人，知道自己的判断在哪一类裁决上值它的摩擦——并据此分配 | 押 / 校准回执 / 归因 / 换挡（软合同）；「我的判断」取景框——见[《私账层-终极设计》](./私账层-终极设计.md) |

**检验标准（v4 修订）：**

1. 一个任务从群里一句 `@agent` 到交付的云之家文档，全程不需要思考"我在哪个应用里"；
2. 每次开口都清楚地知道"这句话谁听得见"；
3. **动词 × 投影完备矩阵**（取代 v3 的"桌面单屏"；v4.6 补第七动词）：操作者的七个动词——委派、监控、steering、审批、验收、记忆维护、**作为同事说话**——每一个在操作者所在的任何投影上可达（IM 习语兜底）；**桌面保留的独占职能只有两项：结构化编辑与深度审计**。外勤剧本证明：以 surface 定义完整价值隐含了"操作者坐办公室"的人设错配，兜底会事实上成为主形态；
4. **管理者检验**（v4 新增）：部门的全部承诺——无论执行者是人还是 agent——在一个取景框里可见、可跟踪、可汇总；
5. **环路检验**（v4.3 新增）：六大环路（委派/目标/会议/工件/人类承诺/注意力）中，人只出现在**决断点**（验收、裁决、授权、定方向），不出现在**搬运点**（回执转告、状态誊写、链接搬运、影响面枚举）——**人不做任何回程的泵**；
6. **成长检验**（v4.25 新增）：**拿走系统的那一天，人比第一天更强**——杠铃与拐杖的分界；可观测版：第六个月的人，敢裁第一天不敢裁的事，且每一份"敢"都有判例与对表作证据，不是感觉。**v4.28 可证伪版**：30 天不烦（回喂事件 ≠ 0）→ 一季分配动了（至少一族按判例换挡）→ 一年自知带得走（不看账能说出自己在哪些族值、哪些不值，且与判例一致）——一年内只能证伪不能证实。

**摩擦再分配（v4.13，Bruce 裁决入终极价值层）：**

> **本产品是组织的摩擦再分配机——把摩擦从搬运处移走，安放到决断处，并且不碰社交处。**

组织摩擦力分三种，混为一谈会毁掉产品：**①损耗性摩擦**（搬运/转录/找入口/等待不可见/汇报仪式/对齐表演）——归零，产品九成机制在干这件事（回程律、传送门、零维护目标、幽灵承诺禁令皆此类；Viva Goals 死于 update tax = 摩擦税收不抵支）；**②主权性摩擦**（签发/裁决/验收/听众选择）——**主动保留甚至显式设计**：确认卡是给写操作装的摩擦片、人签发是给目标出生装的门槛、宁空勿错是拒绝让挂接太顺滑、「场所人选不推导」保护的正是这类摩擦——刹车也是摩擦，没有刹车的系统不是高效，是失控；**③社交性摩擦**（催办的社交成本/公开承诺的压力/当面拍板的重量）——**不碰**：B4 禁借身催办、催=agent 拟稿+本人亲发已在保护它；承诺的约束力部分来自其社交成本，把催办变成零成本自动通知，承诺的重量即蒸发。此表述是既有裁决的**统一理论而非新增机制**：检验⑤（人不做泵）=损耗侧，三主权时刻=保留侧，B4/听众人选=社交侧，「催人裁决不催人抄数」=其一个切面。它给未来裁决一把新刀——**摩擦检验句：每当产品让某件事变容易，先问这件事的难度是不是在保护什么**。自动挂接再聪明一点、一键验收、代发催办、跳过逐条确认——每一个"降摩擦"的提案都须过此刀；反面即 frictionless 深渊：没人签字、没人验收、承诺无重量的自动化空转系统。

**P′ 层现行规格（v4.28，决策 #64）= [《私账层-终极设计》](./私账层-终极设计.md)**：终极产出 = **自知**（知道自己的判断在哪一类裁决上值它的摩擦）；四动作、零新场所、八条法、十七项证据门。以下 #60–#62 各段保留为**演进史**，与终极设计冲突处以终极设计为准；其中被保留的条款（判别式、双账、摩擦四分法、产婆术、硬合同、持镜人、立此存照、不可回填、无分数）在终极设计 §5 与 §8 对照表中逐条指认。

**P–agent–P′（v4.25，Bruce 裁决入终极价值层——复利开双账，决策 #60）：**

> **产品的回路必须是 P–agent–P′，不是 agent–P–agent′——判据不是参与、不是主权，是回路终点的增量落在谁身上。**

两个回路元素相同、动作相同（人都参与、人都握着批准键），唯一可观察的判别式 = 谁带着增量归来（C–M–C′ 与 M–C–M′ 的判别法）。审计结论：本节复利四载体（记忆/工件/流程/信任）全在系统侧——v4.24 及之前的设计给了人**不变薄的护栏**（三主权时刻、社交摩擦不碰、反剧场），没给**变厚的回路**；被解放的时间只是潜能不是成长。**权力是门，能力是肌肉——门可以一扇不少地保留，而门后的肌肉全部萎缩**；透明救不了：现代圈养不用铁栏用玻璃，轨迹/回执/审计让人**观看**，观看不是练习。此修正非人文附加，是**可信度的承重墙**（从反剧场内部推导）：主权时刻的质量依赖主权者的厚度——提案质量越高 → 驳回率越低 → 裁决信息量越低 → 人越不细看 → **温水剧场**：三主权时刻退化为三剧场时刻，"可信地完成"自塌。四条入宪：

1. **复利开双账**：组织的图与人的判断力，两本账同为终极价值（价值表补"人的复利"行；成长检验入检验标准⑥）；
2. **摩擦四分法**：损耗归零/主权保留/社交不碰之外，第四类**成长性摩擦（构成性难度）**——难度即内容的事（想清"可验收"、判断交付好坏、开口催人），消灭它等于消灭它本该生产的那个人；摩擦检验句的第三个答案：有些难度保护的是人的未来；
3. **产婆术条款**（既有裁决的公分母命名）：凡构成判断力的表达——委派内容、成功标准、催办话语、预期与归因、裁决本身——**agent 只能接生，不能代产**（提问/结构化/备料/举证合法，代写非法）；磨目标"作者权≠思考伙伴"、预填出处律"内容由人说"、催=拟稿亲发、差距简报"判断由你下"全是它的实例——命名它，rubber-stamp 漂移有了守卫者；边界：**难度长在真实决断里，不长在仪式里**（强制写验收理由 = 亲手制造对齐表演——反剧场对本条款自身适用）；
4. **给人修回程律**：人不断发出裁决边而无回流边——按图自己的记账法，这就是 agent–P–agent′ 的拓扑学定义；**校准回执 = 当时裁决 × 后来事实**（原料图已天然生产：裁决留痕 × 终态回流），落**私语域**，归因由人自己下（归因四格：对了·因判断/对了·因运气/错了·因判断/错了·因世界——四格防两种自欺）；**预期 = 对话式立约**（可选、一句可证伪的赌注、绝不做表单字段、**不可回填**——预期在裁决时刻出生）。

**判断力档案硬合同**：仅本人、不入组织图、不可导出、永不进任何聚合与绩效——误判史归组织，成长回路当场翻转为监控回路（"无上级驾驶舱""席位诱惑明拒"同族律；§1.6 隔离哲学的最后一次应用：你的误判史谁听得见——只有你）；耦合单向：组织图作为证据源流向个人私账（金库），永不反向。**租约入口两读**：连续高通过率 = 该租约化（裁决无信息量）或该警惕（人不再细看）——租约提议须亮出证据并给两个出口（设为租约 / 加负重：摆开证据慢下来），选择权在人。**圈养的定义 = 单回路**（一条链的增长以吞噬另一条链为代价）；健康形态 = **双螺旋**：agent′ 的增量来自人的话语与裁决，P′ 的增量来自被扛走损耗后**保留且回喂**的判断；逐环判据：同一次点击，反馈只流回系统是萃取，也流回人是练习。**验收句：拿走系统的那一天，人比第一天更强**（搬运的肌肉不值得保留，那是老茧；判断/表达/关系的肌肉萎缩即圈养）。机制近零新增：校准回执 = 可应答对象落私语域（复用单答家族）、预期 = 登记动词的私语形态、租约两读 = 既有租约提议卡补一个出口；唯一新增的"面" = 私账对表视图（金库），且它住在私语域——与个人参谋线（metacognition_os）单向耦合：图供事实流，金库炼判断。

**同回合 review 七收紧（v4.25r，Bruce 令深查"是否真第一性"后的自审回执——三类失足自纠：①硬合同一刀切在最关键处自违判别式②新回路与注意力宪法的接缝未裁决（补名词不补接缝）③两读未做同类全集扫描（守裁决侧漏生成侧））**：

1. **私账三不入**：校准回执/立约邀约/两读卡**不进收件箱、不进决断条、不进任何可应答聚合徽标**（收件箱是组织的账的唯一聚合处；私账对象的在场方式 = 私语域未读【消息层语义，读即清】与金库本身）；未答回执**不老化、不可催、不成欠账**——这本账的债主是你自己（回执是邀约不是待办，攒着不答完全合法）；
2. **金库数据律**：私账真身 = 个人域图数据（host 内存不是真身——确认卡教训适用，重启可恢复）；**审计导出不可触及**（对称保留律"永不记忆场所"之后的第二例外区）；**"不可导出"精确化 = 组织与他人不可导出、本人可整体取走与销毁**（初版一刀切错误——组织扣押成长账本 = Org–P–Org′，数据主权归人）；部署二值开关：组织可整体不启用金库，**"启用且组织可见"的中间态明拒**（比不启用更糟——戴着成长面具的监控）；
3. **持镜人条款**（金库对 agent 的消费限制）：agent 只能在**人发起**的对表/回看/换挡时刻引用金库内容（备料举证），**不得把金库模式静默转化为组织侧行为变更**——不得因你的误判史替你加门、挡你裁决、调整提案策略（"以帮你成长之名采集行为喂系统"是判别式最阴险的违反形态；加负重必须由人签发）；本人行为事实（停留时长等）可入私账作镜子的证据，但永不进入任何组织侧通道与模型调优——**镜子只能被本人照，agent 是持镜人不是整容师**；
4. **三档位定律**（两读的同类全集扫描——温水剧场的另一半是生成侧萎缩：拆解/方案能力，不只裁决侧）：每个提案族有三档——**租约**（全自动）← **默认**（agent 提案、人裁决）→ **负重**（人先手、agent 补充——产婆术的可调节形态："我先拆，你再补"）；档位是人的**私有设置**、金库证据辅助换挡、换挡台在金库；条尾「这类裁决还需要你吗›」既有入口即换挡的组织侧就近入口（v4.15 条尾租约入口的语义扩员，零新入口）；
5. **邀约疲劳治理**：立约邀约被连续不立 N 次 → 该类时刻降频停问（人用脚投票即应答），重新开启主权在人、入口在金库（条长即疲劳信号的对偶）；
6. **P′ 四资产明标**：判断 = 金库回路（#60 唯一新增机制）、表达 = 产婆术（命名既有）、品味 = 磨稿亲笔（既有）、志向 = 目标作者权（既有）、关系 = 社交摩擦不碰（既有）——**金库只机制化判断；品味与志向的量化明拒**（机制化即其死亡——"品味 72 分"是教练剧场）；
7. **产婆术显示层收紧**：归因候选的措辞只能是**证据与假设**（"简报③当时已在卡上"），不得是心理判词（"没当回事" = 替人写好的归因——违规）。

**P′ 环行闭合（v4.25+，决策 #61——Bruce 令全局 review"确保完整闭环而非零散功能"的回执）**：

审计方法 = 用设计自己的闭环学（回程律 / 环行自检 / 数据律七条 / 既可见又可动）逐对象走查 P′ 全部居民（预期/校准回执/判例/模式/档位/邀约/金库）。**主发现：环行七分之六——缺回喂环**。模式浮现之后没有回到下一次裁决时刻的合法通道：金库若只能靠人记得来查，就是自己的 Viva Goals（目的地 app 死法——"来取不是来喂"反噬自身）；而 agent 临场提醒 = 说教剧场 + 持镜人违规。**消解：回喂 = 人预先签发的私账规则，不是 agent 临场的好意**——**后视镜 = 负重档的显示形态**：人在金库对某提案族签发"亮出我的相关判例"，此后该族卡片旁（**仅你可见的操作者层**——条尾两读卡已确立此先例）显示判例 chip 一跳回金库；默认不开、人签发、随时可关；agent 照办不揣测（持镜人合规——规则是人立的，agent 只是执行显示）。换挡台由此从"设置页"升格为**回路的合环阀**。

**P′ 环行自检表（八环）**：裁决 →（立约 · 可选）→ 事实回流 → 对表归因 → 判例入账 → 模式浮现（滚动）→ **回喂（后视镜/换挡）** → 再裁决——每环既可见又可动，缺一即割裂债；**凡只能在金库获得的能力即违规**（对账面自检条款的私账版）。

**六项收紧**：①**预期不可改笔**——只可撤回（理由留痕），且同一裁决撤回后不可再立（不可回填的对偶：临近检验点改口 = 组织化的自欺通道，堵死）；②**回执可驳回**——第五出口「配对错了」（事实与裁决无关 = dlvinfer"不是交付"的私账版，宁空勿错；判例不入账、可纠回）+ **校准回执幂等锚 =（裁决边, 事实边）**（同一事实多次回流不重复出执）；③**模式滚动律**——判例永续（你的史）、模式滚动派生（近 N 次 / 90 天，现在时）：金库照现在的你，**不给你建档案**（累积模式 = 给自己建的永久污点账——回路翻转的自我版）；④**重签即对表**——租约到期重签卡携带期间证据摘要（N 单 · 异常 M 单）：**换挡也是裁决、也有回执**，否则租约化的领域从此脱离回路成为永久盲区（回路的出口漏洞，堵死）；⑤**邀约出处限组织侧事实**——立约邀约不得引用金库模式作出处（那是 agent 主动消费私账 = 持镜人条款的第一个漏洞；镜子等人来照，不追着人照）；⑥**词汇卫生**——"校准回执"恒带前缀，不得与交付回执简称混用。

**零散性终检**：补上回喂环后，#60 全部构件在八环上各有座位——产婆术护立约/归因两环的表达权、疲劳治理护邀约、硬合同是全环地基、三档位在回喂环合环——无一悬空。双螺旋随之收口：P′ 增量的落点从"账本"变为"下一次裁决"。

**金库对象面澄清（#61 同回合，Bruce 问"私账右栏的对象面做什么用——最终设计是这样吗"）**：demo 初版右栏放的是理论卡片（双螺旋/验收句/机制账单）——**注解内容冒充产品面，判错**（理论住注解层，产品面只住对象——annotate 分界的本意）。正解三句：①右栏语义单一形态不变（"中栏是流、右栏是物"）——金库的物 = **判例的证据锚**：选中判例/预期/回执行 → 右栏归集其锚对象（当时的裁决卡、简报条目、事实消息、工件）只读预览、一跳可回真身——**对表不出屏**（"验收不出屏"的私账对偶：边看证据边下归因）；默认态 = 待对表项的证据备料（**打开金库 = 人发起的回看时刻**——持镜人条款"人发起"的消费时刻定义，备料不定案）；②**判断力档案硬合同 = 合同面板同构**——五条硬项 + 持镜人条款住进合同面板（与场所合同同一语法：guard 强制、面板可检视），不散落为说明卡片；这份合同的特殊性：**另一半签署人是你自己**；③**金库 ≠ 记忆**——记忆是 agent 的复利、金库是人的复利：记忆 tab 在金库语境空态明标"金库内容永不入记忆库"，两本账在右栏也不合流。**接缝（#62-A 合回后补）**：证据面受摘要立此存照律约束——**摘要为主、锚为辅、锚死显形**：右栏归集的第一行永远是私账自存的人可读快照（照片），锚只供一跳回与活性探测（链接）；锚死时快照原样在场、行上显形「真身已变/已亡」——对表不出屏在组织侧对象亡故后依然成立（否则证据面纯靠锚 = 判例是空壳在显示层的复发）。

**对象面账本律（#62 追加澄清，Bruce 问"从群切到私账，右栏是不变的吗——切换逻辑没讲清楚"）**：右栏没有自己的身份——它是**当前会话的物的投影**（"中栏是流、右栏是物"既有语义），切会话即整体重算：右栏 = f(当前会话, tab)。由此四句：①**账本随会话整体切换**——物有账本归属而两本账永不合流：组织侧会话（群/话题/DM/板/枢纽）的右栏**结构性不含**私账对象；私账内容进入组织侧屏幕区域的唯一通道 = 人签发的回喂显示（后视镜/条尾两读——#61 仅你可见层，受演示隐身 D10 管辖），且它们是**行内条，永不进右栏**；②**残留面 = 第四泄漏口**（继聚合面/导出面/搜索面之后）：切离私账会话时，证据面选中态与私账预览**即收**——"切会话即收"对私账内容从整洁纪律升格为**泄漏面条款**（投屏/共享屏幕场景下，右栏残留的判例即泄漏；demo 的选中态跨会话残留是此空白的第一个违规实现，已纠）；③**三 tab 账本归属各自恒定**：当前 = 跟会话走（账本随之换）／记忆 = agent 的复利（金库语境空态明标，既裁）／资源 = 组织侧全局浏览器，**唯一跨账本恒定格**——单向可见：私账语境可看组织的物（你的可见域本含），组织语境永不见私账的物——**耦合单向律（图→金库）在显示层的投影**；④金库右栏的"组织的物"恒为**快照非本体**（#62-A1），一跳回真身 = 一次整屏的账本切换。

**P′ 二次全局 review（v4.26，决策 #62——Bruce 令"针对私账层大量更新"的回执）**：

审计方法 = 三把**设计自己的刀**，逐把过一遍私账全部居民（预期／校准回执／判例／模式／档位／邀约／后视镜／补登事实／金库）：①**取走律刀**——把目录拷走之后，这本账还成立吗；②**#61 自己的刀**（"凡只能在金库获得的能力即违规"）——对 #61 自身适用；③**同类全集刀**（每个可见状态要有出生故事）——扫**裁决面全集**，而不是枚举触发点。**主发现三条**：

- **①判例是空壳**：私账正文的"事实/证据"是**引用**组织图锚、内容靠锚解析。于是"目录自包含、拷走即取走全账"与"锚失效不蒸发内容"**两条同时为假**——组织侧墓碑一落，你取走的是一叠指向虚空的编号。数据主权在**实践层面**仍被扣押（"技术上可取走"是扣押的另一种拼法）。
- **②环7 的入口垄断在金库**：后视镜与换挡只在金库开，而最想合环的时刻是**刚答完归因那一刻**——判断刚出炉、动机最热。#61 立的条款，第一个违例就是 #61 自己的后视镜。
- **③环1 的裁决面靠枚举**：立约触发是两个枚举点（验收 accept／简报验收），可金库里躺着委派锚与续约锚的预期——**这些可见状态没有出生故事**。枚举不是判据。

**修法十条（四组）**：

**A · 账要立得住**

1. **摘要立此存照律**：凡组织侧内容入私账，恒**同时**存当时的人可读摘要（当时／事实／证据三段文本快照）；锚只用于**一跳回**，永不用于**内容解析**——**私账存的是照片，不是链接**（环境快照律在私账域的形态）。自包含与"锚失效不蒸发"由此同时为真。
2. **人可读取走**：取走的兑现形态 = 人能读的全史（判例册 + 原件并存），不是二进制目录。逐级兑付定律对取走律适用——**给不出人能读的东西的"可取走"，是明拒条款上的幽灵信号**。
3. **锚死显形（前提消失）**：预期所锚的组织侧对象进终态／墓碑／作废／移交 → 该行显形「前提已变」+ 就地双出口（撤回 ／ 照旧对表）；**不自动撤回**——撤回是人的诚实动作，代撤即代产。回程律对私账的兑现：**锚有余生，预期也有**。

**B · 环要合得上**

4. **可对表判据取代触发枚举**（环1 的全集扫描）：立约邀约的出生条件 = 三条件合取 + 一个否决位——①图上有一条**人签发的裁决边**（有留痕可锚）②有**可命名的检验点**（时间点或将至的事实）③**事实会自行回流**（图内结构性回流可及，或人工补登够得着）；④否决位 = **信息量**——高频低信息的裁决即使三条全过也不问（邀约变 nag 是邀约疲劳的生产线，治理疲劳不如不生产疲劳）。判据定谱：验收 ✓／差距简报验收 ✓／**委派签发 ✓**（交付时间与质量是天然回流事实）／**打回·返工 ✓**（高信息裁决）／租约签发 ✓（#61 重签即对表已定）／确认卡 ✗（判据④）／目标签发（周期跨季，押证据门）／移交·作废（期中修理，押）。金库里那两条预期由此获得出生故事。——**扩触发面必同扩治理面**：邀约疲劳治理随之从"族级连续不立降频"扩为**族级 + 全局配额**双层，否则判据④在总量上被绕过（五个入口各自克制，合起来仍是骚扰；**扩员即疲劳，是同一个动作的两面**）。
5. **就地合环（环7 的入口不垄断）**：凡"人刚获得一个判断"的时刻，**合环动词就近**——回执答完归因的终态即带就地的开后视镜／调档／关镜；金库是**汇总处**，不是唯一入口。#61 的条款由此升格为通则，并对自身生效。
6. **静默沉降律**：待对表超期与未答回执在私语流里**折叠归并**（"3 张待对表 · 一起看 ›"），过期后沉入金库「未对表」区——不变红、不计数、不催。"未答不成欠账"此前只是文字承诺：**堆积是催办的被动形态**，显示层会自己长出欠账感，私语通道会变成第二个收件箱。

**C · 镜子不替人说话**

7. **隐式预期不得措辞化**：无显式预期时，回执的"当时"栏只陈列**裁决事实本身**（"你在 8/30 10:30 验收了《竞品对比 · 评审表》"），**不代人推演其含义**——"隐式预期即'它已经够好'"是 agent 替你写好了你当时在想什么。产婆术在回执正文的第三处应用（与预填出处律、归因候选措辞同族）。
8. **归因分布镜**：模式区陈列四格分布本身（滚动窗口内 q1/q2/q3/q4 各 N，每个数字是门），**不给判词、不给建议**。防四格的第三种自欺——单次归因防不住"永远选 q4（错了因世界）"，分布能；而一旦系统替你解读分布（"你在推卸责任"），它就从镜子变回教练。**陈列是镜子，解读是教练**。

**D · 泄漏面封闭**

9. **私账动词族明拒**：私账卡与金库行**没有转发／分享／引用到组织侧的动词**，私账内容不进任何 @提及与引用语法的可选源——**不给动词就不会误用**（#57「占位即全域不可达」的反向应用：此处的不可达是特性）；人自己复制粘贴是人的自由，系统不递刀。
10. **搜索面条款**：本人可搜自己的金库（viewer=operator 的合法查询，落点只有金库与私语域、结果标私账域）；**组织侧搜索索引结构性不含私账**（与"三不入靠存储分离"同款）。查看者样本律的搜索面兑现——此前只裁了聚合面与导出面，**搜索是第三个漏口**。

**零散性终检（二次）**：十条各归其位——A 组托住"账"这个名词（无自持即无账）、B 组补环1 的判据与环7 的就近、C 组守产婆术在私账仅剩的两处显示层、D 组封硬合同两个未裁的面。**八环不变**（不新增环 = 不新增机制）；新增的唯一"件" = 摘要快照与判例册导出，二者皆是既有律（环境快照／逐级兑付）在私账域的兑现。

## 1. 第一性原理

### 1.1 一张会话图，任意投影

组织基座（云之家：身份/通讯录/权限/消息/文档表格，经 CLI/API）是基础设施；**会话图是唯一的产品实体**；桌面工作台、移动端、云之家原生消息，全部只是图在不同设备、不同采纳状态下的投影。拥有会话图的人赢，surface 越便宜越好；不赌云之家客户端的存亡。

### 1.2 三条正交的轴

| 轴 | 区分的是 | 设计结论 |
|---|---|---|
| 社交轴（公/私） | 这句话谁听得见 | 真实边界，保留并锐化（自变量的精确定义见 §1.6） |
| 设备轴（桌面/移动） | 操作者当下的带宽 | 同一个产品；桌面先行，移动后置；**动词可达性不分设备**（检验标准③） |
| 采纳轴（装了/没装/组织外） | 对方与产品的关系 | 未采纳者经云之家消息触达（兼容投影）；**组织外实体经影子节点与脱敏导出触达**（v4 新增一格） |

### 1.3 IM 是 UI 习语，不是产品边界

气泡/会话列表是"渲染对话"的习语，卡片/面板是"渲染对象"的习语。工作台各取所需。"IM 和 agent 怎么合并"这个问题本身问错了——从来不存在两个东西。

### 1.4 设计对象，不设计界面功能

审批、等待、终态、记忆、承诺、裁决——每个都是图上的对象，一次定义、N 面投影，任一投影上的应答全局生效。审批对象的"桌面卡 + 云之家 DM 兜底"已验证此路（六剧本五处高光）；v4 把它贯彻到全部六个操作者动词。

### 1.5 图的居民（v4 补全）：四个单元

> 会话是**交互单元**，工件是**产物单元**，**承诺是工作单元，流程是复利单元**。

v3.6 只建了前两个。六剧本中五个独立撞上后两个的缺失（经理的"让张三负责 B"不入图、HR 六周招聘无真身、行动项发出即消失、月结每月推倒重来、高管"盯人"不可得）——这是业界结论"C 门面 + A 协议 + B 记录"里，**模式 B（任务对象中心）只建了一半的欠账**。v4 图的一等节点：

- **会话**（话题锚定，v3.2 边界规则不变）；
- **工件**（含版本系列与血缘边，见 A7/O5）；
- **承诺**：`{做什么, 执行者(人|agent), 期限, 状态, 父承诺/父目标引用, 来源会话, 血缘}`——执行者为 agent 时即现有话题会话的任务面；执行者为**人**时，agent 是观察者与（F-read 供电后的）跟催者；**父子边是承诺的通用边**（v4.1：目标 = 复合承诺；流程 = 带模板的复合承诺特例）；
- **流程**：承诺的模板化容器——**结构（模板/子任务/系列/重复同构）现在建，推力（定时触发）归域 F**。"推迟结构等于把复利率因子在重复性工作这个最大场景上判缓刑"（财务剧本）；D8"现在建边，将来供电"原则原样适用；
- **事件**（时间锚，v3.6 五边模型不变）与**实体**（联系人；含组织外影子实体，域 H）。

节点之上，两个新**取景框**（收件箱=注意力、群视图=场所之外）：**跨执行者**（承诺板：部门的人+agent 承诺一屏）与**跨时间**（周报/月结总控的 pull 版汇总）。克制：不做甘特图/依赖图/资源视图——承诺是节点+边+取景框，不是项目管理子系统。

### 1.6 隔离函数：自变量是"听众集合"，不是"agent 驻地"（v4 重述）

检验句"这句话谁听得见"早已给出答案，v3.6 却把记忆与检索焊死在场所上（组织级事实要两群各删一遍、客户知识被群切碎）。重述为三条：

1. **读取侧**：私语态下 agent 以**提问者本人的可见域**为界读取（他本来就看得见销售群——替他跨场所检索对人是零泄漏）；公域输出按**在场者最小交集**隔离；
2. **越境侧**：跨场所信息进入公域的唯一合法通道 = **人签发的工件化脱密**（入池、A4 摘要——已在事实上实践，v4 成文）+ 越境审计 + 血缘记录；
3. **记忆侧**：场所轴之外补**实体轴**（客户/对象——销售的复利单位是客户不是群）与**组织轴**（组织级事实单一权威副本，场所记忆引用不复制）；**"永不记忆"入硬合同**——能力越界可撤销、记忆越界不可撤销（高管机密剧本，致命级）。

**听众集合的解析语义（v4.18 成文）**：听众集合**按场所解析、随成员动态**——audience 存场所引用、不展开成员快照（技术方案 v2.5 既定约定升格为设计语句）。检验：新成员进群后在云之家看得见历史登记消息，则承诺板同样看得见对应承诺行（两端一致）；做成登记时刻快照会产生"IM 看得见、板上看不见"的分裂。成员变更（拉人=听众扩张、移人=听众收缩）因此是**听众敏感操作**，走确认门。

### 1.7 会话边界：话题即公共句柄

锚定层级：原生话题 ID（infra ask）> 回复链根 > 自成根；永不语义/时间自动归并。检验句：云之家里看见在同一话题，就在同一会话。**v4 修正（DM 特例）**：私聊裸消息**不再自成根**——一个联系人默认一条连续会话，显式 `/new` 分段（A0③ 在 DM 的反噬：会把私聊流碎成 N 个会话；"一个联系人一条流"才是 DM 场景下与用户所见一致的边界）。

### 1.8 回程律：边有出生，也有余生（v4.3）

[割裂点复盘](./scenarios/复盘-割裂点.md)（26 缝、三路独立收敛）暴露了一个对称性破缺：不可回填裁决刀只被用在了**出生边**（登记、挂接、血缘、蒸馏来源）上，而环路闭合依赖的全是**回流边**——回执、凭据、状态回写、记忆注入、冲突对撞。"张锐在电梯里说明天给"这个回执时刻、"哪个会话消费了哪条口径"这个注入时刻，同样**发生即逝、不记即失**。由此三条定律级修正：

1. **回程律**：每条边都有出生与余生；不可回填裁决刀必须**对称使用**——回流边与出生边同权进 P1 数据位；
2. **可应答检验**（§1.4 的贯彻检验）：凡向人提出问题的东西——提醒、挂起、定向询问、租约提议——都必须是**可应答对象**而非文本：应答即回写、任一投影生效。§1.4 至今只在确认卡上兑现（DM 兜底审批是全设计最成功的验证），欠账即割裂；
3. **动词以节点类型为参数**：盯(节点)、登记(话语→节点)、移交(节点, 场所)——按功能名枚举必掉缝，按节点泛化一次收敛。

哲思收束：对象学三问至此闭环——**出生地是对话，户口由采纳轴定，余生由回程律保**。图有了名词与出生证之后，v4.3 让它开始呼吸。

### 1.9 七条数据律（v4.4）

[数据流复盘](./scenarios/复盘-数据流.md)（八阶段 × 20 类数据、三路独立审计、32 行问题收敛）的定律化产出——全部为原则级，零新机制：

1. **真身唯一律**：每类对象声明唯一真身（图或云之家；**host 内存与浏览器缓存永远不是真身**）；投影允许滞后、禁止错序、滞后必须可见；**可应答对象的待答状态即图数据**——host 重启后可恢复、可应答（确认卡曾活在 host 内存的教训，从个案修复升格为族律）；
2. **先答先赢律**：并发应答按图追加序**首答生效**；后答者收到"已由 X 在 Y 投影应答"；同语义重复应答幂等为 no-op；全部应答留痕；
3. **更正即追加律（墓碑总则）**：一切更正 = 追加替代/墓碑事件，读取投影折叠，**永不重写历史**；纠正权随原对象的应答权（公示同 steering）；合规抹除 = 墓碑遮蔽投影，真身保留（唯一例外见第 6 律）；
4. **真身之变律（第五类回流边）**：凡图外真身（目标/工件/事件/审批单/实体/场所），引用必须配三件套——**消费时点校验、断链显形（不静默、不自动重挂）、人工回填动词「真身已变」**；场所消亡、会议取消、文档删除、成员离职同入此律；webhook 到位前这就是 P1 降级形态（环路完整性检验的兑现）；
5. **读取环境快照律（第三类边）**：出生边、回流边之外，按"**时刻**"横切的第三类——会话运行所依据的环境（锁定的合同版本、生效中的租约、注入的记忆、喂入的引用）在**使用时刻**记录；"当时依据什么授权/判断"由此可审计；流程实例记"源自模板哪一版"同入此类；
6. **对称保留律**："不留"与"留"同权——默认历史永续（审计与复利资产），收敛靠视图、清理只在派生缓存层；**唯一例外：永不记忆场所**——其会话日志可读域继承场所合同、**审计导出不可触及**、保留期与抹除权是硬合同条款（否则"永不记忆"被日志层架空）；策略事后改严：**撤销类硬项穿透快照**即时生效、配置类随快照、回溯清除经显式确认；
7. **幂等锚与显式合并律**：凡多路径可创建的对象（承诺多路登记、实体多场所出现、纪要重复摄取、再蒸馏）必须声明**幂等锚**，或提供显式「合并」「作废」动词——禁语义自动归并的对偶：**不自动合，但必须能手动合**。

**代码资产**：`topicKey↔sessionId` 持久锚定；turn 级写权限治理（guard、逃逸封禁、identity pin）；41 个工具（doc/sheet/calendar/contact/im/file）；session-hierarchy 雏形；小窗的 IM 渲染与发送能力。**断层**：IM 消息不落库；审批曾锁桌面（A2 已解）；借身说话；上游两依赖（RFC-1/2）。

**剧本压测（v4 新证据源）**：六视角 80+ 缺口收敛为 §1.5/§1.6/域F拆分三个结构级结论；同时确认强项——DM 兜底审批（五剧本高光）、事件枢纽、双语态隔离、终态退租、异步抗弱网、治理拨盘。

**对接裁决刀（v4.17，元教训成文）**：平台对象在本设计中只能扮演三种角色——**投影**（触达面：待办/卡片/通知/日程条目）、**证据源**（回执/签字/应答状态）、**素材段**（brief/洞察/纪要原料）——**图的本体论一寸不移**：承诺/会话/听众集合等图的原生居民，真身永远在图（与"目标真身外挂云之家"不矛盾——那是采纳轴对"组织在哪里看它"的裁决，不是本体论移交）。每条对接结论必须过此刀。v4.16 曾有三条未过（"真身"误标 user-action-item／"中间态"过设／摄取听众未接线），v4.17 逐一修正——**对接盘点最大的风险不是接口拿不到，是被平台的对象模型带偏图的本体论**。

## 3. 设计总纲：八个设计域

### 域 A · 图对象层（价值最高，无上游阻塞）

**A0 会话边界**：三级锚定 + 边缘案例表（v3.2）+ **DM 默认连续**（§1.7）。ack 教学引导、`generation` 换代、`/fork` 分叉、场所内会话互读、归档重开——均不变。**v4.5 补一句：回复是边界的输入动词**——回复链本就是话题锚定的基础设施（`replyRootMsgId`），故话题视图内的公语态发言**技术上必然是一次回复**（自动锚定话题，否则自成新根）；群视图内就地回复某条主楼消息 = 入链（话题诞生的自然入口，A0③ 的另一半）。设计一直隐式依赖回复机制，v4.5 把它交还给用户。**v4.7 收拢为一条定律：回复 = 挂链，落点 = 链根所在的边界，边界规则决定链是否划界**——群：**冷链平铺，热链收纳**（Bruce 裁决）：挂链是数据事实（`replyRootMsgId` 云之家本就记录），划界收纳是**投影决策**，二者分离——人-人引用链**平铺主楼**（与微信/云之家原生两端一致，一句「收到」不该重构主楼）；链上任何消息被**受话 agent** 的瞬间，session 锚定链根、**整条链就地收纳为热卡**，此前的闲聊自动成为话题的开场上下文——**链是话题的胚胎，受话 agent 是点火**；原生话题云之家自己收纳、我们跟随。锚定层级「回复链根 > 自成根」在含 @ 时同样生效——回复着某消息 @agent 即入其链点火，**不**自成新根。DM：流即界（§1.7 一个联系人一条流），回复自动退化为纯指涉、落点不变。三种实例同一条定律：DM 永不划界、群冷链暂不划界、群热链划界。配套裁决：**「新」是推导不是选择**——用户只选择「站在哪、对谁说」，"新话题"是「主楼 + 受话 agent + 未挂链」的系统推导（A0③），DM 的 `/new` 是唯一显式换代口；把「开新话题」当成用户要理解的模式，正是对话器混乱的根源。

**A1 等待可见（v4 扩展）**：阻塞时话题内回帖"⏸ 等待 X 确认/输入"。**等待对象从"操作者"扩展到"任何第三方"**（HR 剧本：等用人经理反馈三天是收件箱三态之外的盲区）——等待状态标注被等待者与已等时长，可挂在承诺节点上。**冲突可见（v4.3，等待可见的失散双胞胎）**：串行队列检测到与进行中指令**相反**的后到 steering 时，回帖「⚠ 与进行中指令冲突，确认前暂停」——两端机制俱在，成本一条消息（剧本4：相反指令被静默串行覆盖，文档一天三反转）。**等待对象生命周期（v4.4）**：解除路径除回执外，补超时升级与所属任务取消的级联终态；同因重复阻塞复用同一等待对象（幂等锚律）——"已等时长"不可以无限长且无人知晓。

**A2 审批对象家族（v4 扩展为家族）**：
- **确认卡**（写参数确认，多投影 + DM 兜底，不变）；
- **裁决卡**（v4 新增，O1）：面向"agent **发现**的事"——306 行对账 3 处差异，逐条证据锚点 + 确认/驳回/挂起，与"要写的参数"是两种人机交接界面；
- **授权租约**（v4 新增，O2）：对象级 + 期间级可过期预授权（"本表本期记录写入免确认，8/1-8/5 有效"）——与注意力租约同构，解"全确认 vs 审批疲劳"两难；
- **粒度与节流**（O7）：拨盘从"对场所"细化到"对人/对事"；连环审批批量化 + 节流。
- **裁决卡扩展（v4.3）**：第四动词**转办**——对某条发现立一条 executor=人 的承诺，自动携带证据锚点与血缘（剧本5：让采购去对宏迈，发票号人肉带过去、回执无处挂）；**挂起项亮相**——挂到父承诺/验收处（状态计数信号同构：挂起不阻塞，但绝不静默丢失）；**提案裁决**——裁决卡从"agent 发现的事"泛化到"agent 提取的**承诺提案**"（会议决议→批量承诺的桥：纪要进来后逐条 确认/驳回/挂起，免去八条决议逐条人肉登记；摄取押 infra 门，桥本身冻结内）；**交付即出卡（v4.14）**——终态回帖本身升格为可应答对象：**验收卡**（验收/拒收动词长在交付上，带"等你验收"的脸）——可应答检验当年漏掉的第六员；用户找不到验收项的病根不是它滚走了，是**它长得不像一个等你的东西**；

## 4. 治理与安全

继承全部既有机制（turn 级授权、source 派生、逃逸封禁、identity pin、DM 兜底审批威胁模型、硬合同仅结构化编辑）。v4 新增：

| 对象 | 治理要点 |
|---|---|
| 授权租约 | 显式期限、到期自动收回、租约创建本身走强确认；租约清单在场所合同面板可见 |
| 裁决卡 | 裁决记录入 session log（审计基底）；挂起项不阻塞其余执行 |
| 越境审计 | 工件化脱密动作留事件：谁签发、从哪到哪、脱了什么 |
| 记忆策略 | guard 级强制；"永不记忆"场所的会话不产生蒸馏、不进任何轴 |
| 审计导出 | 凭证级追溯单生成走确认；导出物含完整授权判定链 |
| on-behalf-of | 名义随消息投影展示；借身期跨场所催办直接拒绝 |
| **在岗（v4.27，#63）** | 群场所至多一个在岗实例；接单 = 人签发的身份/听众敏感动作，**向群发一次在岗声明**（"谁把 agent 接进这个群"的审计面就是群本身——三方知情零新机制）；退岗同帖；在岗移交 = 退岗声明 + 在岗声明（场所记忆随包须人签发的脱密，私语不迁移） |
| **署名（B2 升格）** | 寄生期 agent 一切公域出站消息恒带署名「—— 云小助（Bruce）」：对人 = 归因（否则没人分得清 Bruce 与 Bruce 的助理），对同侪实例 = 互认凭据（agent 用人看得见的同一条通道发现彼此，不需要成员列表） |

**多实例受话唯一律（v4.27，决策 #63——Bruce 问"我和同事都装了，他在群里 @next，两边的 agent 都干活，冲突了"）**：

> **一个场所，一次受话，唯一接单者。** 寄生期"同一个 agent"是设计上的单数、部署上的复数：N 个操作者 = N 个实例 = N 张图，群里 N 个都叫"云小助"的实体——**名字唯一而实体多**。而寄生身份下 agent = 操作者，"群里两个 agent"其实是"两个人各自把助理带进了同一间屋子"。

人类组织解这个歧义只有三招，每一招都已是本设计的既有定律，本条只是把它们**跨实例适用**：①**点名**（显式受话——回复某实例 agent 的消息即向它受话，v4.7 受话判定天然单数）› ②**地盘**（场所在岗——每个群场所至多一个在岗实例，在岗是人签发并向群公告的主权动作，域 G）› ③**先应者得**（认领竞赛——声明缺位时以群消息流的服务端总序裁决先答先赢，§1.9 律②；**让位必须显式**：一条不撤的 ack 就是一条幽灵承诺——"说了会做而不做"是本产品最不可犯的谎）。一次 @next 到达 N 个 agent = **多执行者事件**，两个都干就是 #58 禁止的自动拆分——到达单数必须过人的手（在岗声明）或过总序（竞赛），**永不过运气**。

**组织的账在 N 张图上**：公域承诺的真身 = 登记者实例的图，其他实例持**镜像投影**——真身唯一律原文直接适用（"投影允许滞后、禁止错序、滞后必须可见"）；镜像行的修理动词按动词主权自然不渲染（owner 是别人），来源实例消失即"信号过时"（三值状态既有）；镜像的外键 = 消息里的句柄（卡片三定律②"消息载句柄"至此成为跨实例协议）。**根治在身份阶梯**：专号给每个 agent 一个可 @ 的名字，受话唯一由平台原生 @ 兑现；机器人/企业应用把 N 张图收回一张——寄生期的本质约束是 agent 的**身份与可用性都寄生在个人账号与个人电脑上**，触发词与认领竞赛都是这段时期的补丁，不是终态。**明拒**：按操作者分触发词（把身份塞进触发词 = 让全群手打路由）；全局锁服务（寄生期无共享后端，且群消息流本就是共享的总序日志）；都干活让人挑（双写不可逆）；随机/哈希选（李四不知道谁的账号会动手——归因不透明）。

**#63 同回合 review 六收紧（Bruce 令全局 review，用设计自己的刀逐角色逐路逐对象走多实例）**：①**同侪出站不是受话**——代发登记话语、让位帖、在岗声明皆实例出站，恒带署名并在分诊最前抑制；否则 Bruce 的代发登记会被张三的在岗实例二次登记——**幽灵承诺的多实例双胞胎**（既有代发与新在岗相撞的必然结果，本轮最重）；②**对象归属是第零级**——回复/命令/卡片动作指向的对象在谁的图谁处理（真身唯一律的分诊形态），跨实例永不竞赛；③**发言者实例优先于在岗**——有助理的人由自己的助理接单（**真身跟说话的人**：委派归因自然、登记归 owner 实例），在岗只服务没有助理的人；唯一律的不变量因此精确化为**"一次受话一个接单者"而非"一个场所一个实例"**——仅本人合同的实例天然无冲突、不发声明，冲突只在 ≥2 个对群在岗重叠时出现（警示 + 押门）；④**梯队高于时序**——认领按梯队（发言者实例 → 在岗 → 备岗）各延一周期，msgId 只裁同梯队，低梯队先 ack 也须向高梯队显式让位（备岗序由此并入同一协议）；⑤**镜像行的动作 = 文本传送门**（主权在我的镜像行有动词，动作经 IM 文本到达真身实例——卡片三定律③的跨实例形态，本地永不改写镜像）；⑥**同侪回写不触发真身之变**（每实例只回写自己持真身的承诺；校验只看栅栏以上人话区）。附：署名可伪造，但**失效方向安全**（错误让位 = 无人接单，永不导向双写）——多实例一切机制的共同验收句：**宁可无人接单，不可两人动手**。

**v4.7 受话判定冻结内澄清（2026-09-03，dsh-2 实测）——显式受话者优先于隐式**：「回复 agent 的消息即向它受话」是隐式受话；消息显式叫了人（@某人 / @所有人 / 平台标「有人@你」）而没叫 agent，受话者就是那些人，回复锚不再反过来盖住它。寄生期 agent 顶着操作者的账号说话，同事回复"你账号发的那条"并 @ 你本人，最自然的读法是在跟你说话——实测里助理替人接了单、还要他验收。纯回复不带任何 @ 维持 v4.7 原样；回复 + 触发词照旧触发。

## 5.5 证据门与 P1 瘦身（冻结修订）

**冻结条款**：v4 冻结为设计天花板。剧本是假设生成器不是事实（探针确认偏差、操作者人设偏差、agent 全能偏差——见[元审计](./scenarios/综合裁决-剧本走查.md)§九）；设计的验收只有一种货币——真实使用。六剧本降格为**设计回归测试**，假设跟踪表见综合裁决文档 §九。

**裁决刀**：推迟一项机制，是**无代价的**（可从 append-only 日志重建：一切视图/导出/UI），还是**永久丢失的**（写入时不记录就无法回填：关系/来源/事件）？

**P1 瘦身清单（P1-lite = 真正先做的全部）**：
1. 域 A 原有图对象（等待可见、审批+DM 兜底、终态+拒收、摘要、命令）；
2. **不可回填数据：三类边 + 三个语义字段**（v4.4 定型，只记录、不建 UI）——**出生边（六）**：血缘、越境审计、蒸馏来源（turn→记忆）、承诺登记（含人类执行者）、会话边界（含 DM 默认连续）、父目标引用（URI）；**回流边（五，§1.8 回程律）**：回执登记（人类/外部/审批凭据）、记忆注入（memory→消费会话）、状态变化时刻（含目标真身回写记录）、冲突对撞、**真身之变（§1.9-4）**；**环境快照边（§1.9-5）**：合同版本、生效租约、注入记忆、喂入引用——使用时刻记录；**语义字段**：墓碑（更正即追加律）、应答序（先答先赢律）、幂等锚（幂等锚律）；需同步技术方案图词汇表；
3. **三项纠错**（拆错误耦合，非添置）：F-read/F-act 拆分（路线图事实）、听众集合读取规则、动词×投影矩阵（作为验收标准）；
4. **最小融合面（v4.5，Bruce 裁决）**：融合话题视图（一个话题一个窗口：IM 流 × agent 轨迹一条时间线）+ 双语态 composer + 话题树入口——**融合入口是创始假设，不是可推迟的视图**；裁决刀此前把它归入"可重建"是错误归类：推迟它，dogfood 验证的是管道不是产品，"入口在何处合并"这个创始问题拿不到任何证据（环路完整性检验对最大的入口自我适用）。完整工作台（D1 收件箱/承诺板/对象面/注意力租约）仍按证据门在 P4。

**证据门标注**（机制留在纸上，触发器在现实里）：

| 门类 | 机制 | 触发器 |
|---|---|---|
| 数据先行，视图后置 | 承诺板/时间回顾取景框、对象枢纽、审计导出 UI、版本系列视图 | 数据位 P1 已留，视图随真实需要长出 |
| 疼痛门 | 授权租约；裁决卡 UI；流程模板 | 审批疲劳真实发生；首个真实对账类任务；**同一流程真实跑过两遍** |
| 疼痛门+基建门 | 目标树视图；待办/cloudwork/cloudflow 执行面 adapter（A6.1） | 首个真实"一个目标拆给 ≥2 执行者"场景，**且**平台盘点阶段二回调中继到位 |
| 采纳门 | 多操作者、演示隐身、分层披露、on-behalf-of、外部实体通道、语音模态、定向询问卡片形态 | 部署规模到达对应阶段（单操作者 → 小团队 → 部门级） |

**比例尺律（v4.28，决策 #64——冻结条款的分层化）**：法条密度与使用证据成正比——任何新层在获得使用证据之前只准有脊柱法（≤10 条），其余一律押证据门；每轮全局 review 必须点名至少一件要删除的面或法，只加不减的 review 报告不予接受。缘起：私账层从 #60 到 #62 在零使用证据下长成二十余条法、七个面、next/ 第三大包——review 的刀（回程律／环行自检／数据律／同类全集）对对象的赌注大小不敏感，用在可选、单人、低频的辅助层上照样产出组织级密度的法；只做加法的 review 是单向棘轮；demo 每造一个状态，"每个可见状态要有出生故事"就追认一条法。#30 已是那把比例尺，只是"Bruce 裁决了 #60"被当成了免检通行证。

**环路完整性检验（v4.3 证据门新规）**：冻结按**机制**切阶段门，而割裂按**环路**发生——环路两端落进不同阶段时，人当胶水的时长 = 阶段差，且**门信号被污染**（没人挂接 ≠ 不需要挂接，是没有入口）。两条硬规则：①每押后一个视图/通道，必须给留在 P1 的对象配一个**最小 IM 习语的进/出口**，否则该对象永远收不到用来开门的真实使用证据；②**P1 降级形态必须明标**、不留给实现者即兴（例：借身期跨场所催收被 B4 禁令废掉 → 明标降级形态 = agent 拟稿 + 操作者亲发）。

**唯一未设计的因子（v4.1 预留空位）**：完成质量——v1-v4 全部投入在信任/注意力/复利，"agent 真的把事做对"始终被假设成立（剧本的 agent 全能偏差掩盖了它；业界事实 Devin 3/20 说明它才是真瓶颈）。设计层的质量杠杆是**拒收→学习回路**（打回时"为什么不行"蒸馏为负向记忆/合同修正——现在拒收只回滚不学习）。此域只能由真实拒收样本喂养，故留空位不预设计。

## 6. 非目标

1. 不为同事造客户端（gateway 兼容投影永久保留）；
2. 不追实时性——但记录开放问题："同一张图两个 SLA"（会中 90 秒查数 vs 委派分钟级）值得研究，会议场景的正路是 infra 不是架构实时化改造；
3. 不增殖入口；
4. 不过度承诺自主性（F-act 维持推迟）；
5. **不做项目管理子系统**——承诺/流程 = 节点+边+取景框，无甘特图/依赖图/资源视图、无进度百分比（聚合只用状态计数，父承诺终态永远走人工验收）、**不自建 OKR/目标系统**（组织级目标真身在外部，图上只挂父目标引用——A6.1）；
6. **不做 Motion/Reclaim 式任务排期**（管理操作者的时间分配越出价值域）；
7. 不做语义自动归并（会话边界、DM 碎片、碎片入池一律显式或默认规则，不用相似度魔法）；
8. 移动 surface 在 P4 前不开工（动词兜底通道除外）；
9. 不赌云之家客户端存亡。
