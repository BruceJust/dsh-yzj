# 工作台界面重设计 v1

> 配套原型：[workbench-redesign.html](./workbench-redesign.html)。用浏览器直接打开，顶栏六步剧本从左往右点；`?` 看快捷键，右上角切深色。
> 上位法：[终极形态设计方案](./终极形态设计方案.md)（冻结）· [私账层-终极设计](./私账层-终极设计.md)。本稿**不改对象模型、不改 RPC 语义**，只改桌面工作台（`next/surface` + `next/cards` 的客户端半）怎么呈现、怎么回应。
> 日期：2026-10-21

---

## 0. 结论

现在这版功能都在，但界面替设计文档说话、而不是替用户做事。三处根病：

1. **规格语言上了屏**：界面在为自己辩护（"委派是传送门：把你送到该说话的地方…"），用户得先读懂设计哲学才敢点。
2. **一切等重**：18 种字号、约 370 处写死颜色、一行十几个胶囊。颜色不再表示「出事了」，于是真正出事的那一行也不显眼。
3. **骨架是 IM 客户端**：左栏是 58 个群加 35 个私聊。可云之家本身就是 IM 客户端，工作台的价值不在这里。

主张一句话：**工作台只做云之家做不到的三件事——替你攒判断、替你记账、让你和 agent 同屏协作——其余全部退后。**

落成八条界面律（§3）、一套新的三栏职责（§4）、一套视觉系统（§6），分五个阶段改进代码（§10）。有 7 处需要你拍板（§9.2）。

## 1. 第一性原理

### 1.1 工作台为什么存在

周三早上 Bruce 打开工作台。他不是来再看一遍群消息的，那件事手机上的云之家做得更好。他来是因为有三件事只有这里能做：

1. **今天有哪几件事非我不可？** 58 个群里散着要他确认的写入、要他验收的交付、要他定夺的差异。他要一处看全，并且每件都带足上下文，一次拍对。
2. **谁欠谁什么？** 张锐答应周二给的数据没来，郑慧的凭证六天没动静。这本账在 IM 里看不见，只在这里看得见。
3. **和云小助一起做事。** 和它在同一条时间线上说话、看它干活、纠正它。开口之前，永远知道这句话谁听得见。

除此之外的一切，比如浏览群消息、未读数、闲聊，都是云之家的本职，工作台不复刻。

### 1.2 终极价值

上位法 §0 说产品是「摩擦再分配机」。投到界面上，这句话变成：

> **界面自身的摩擦——找、读、懂——归零；主权时刻的摩擦——签发、裁决、验收、选听众——保留，并且是被设计过的摩擦。**

人的注意力是唯一不可再生的输入，判断是人唯一不可替代的输出。工作台就是把注意力换成判断的转换器，**判断数 ÷ 注意力秒**就是它的效率。

### 1.3 体验度量

| 指标 | 现在 | 目标 |
|---|---|---|
| 打开后知道「今天要我拍板什么」要点几下 | 3 枚计数 chip，每枚跳一次才知道是什么 | **0**：左栏逐条列出 |
| 回答一张卡 | 定位 + 鼠标点，键盘做不到 | **≤ 2 步**，键盘全程可达 |
| 字号档 / 最小字号 | 18 档 / 8.5px | **6 档 / 12px** |
| 写死颜色 / 暗色模式 | 约 370 处 / 不支持 | **0 / 全覆盖** |
| 屏上的论证句（解释设计为什么这样） | 几乎每个面板都有 | **0** |
| 主视图里露出的原始 ID、URL、JSON | 有 | **0** |
| 一行里的彩色信号 | 4–6 个 | **1 个** |

前五项可以写成自动检查（§10 P0 的样式棘轮测试）。

## 2. 诊断：现状的八个病

证据来自 2026-10-21 在 3090 上的实测截图，以及对 `next/surface/src/client` 的盘点。

| # | 病 | 证据 | 根因 |
|---|---|---|---|
| 1 | **规格语言上了屏** | 目标页：「委派是传送门：把你送到该说话的地方，句子由你说、发出去才算数」、页尾「闭环自检：…」（`GoalPage.tsx:709`、`:1010`）。右栏标题「对象面 · 流沉淀为物 · 跟会话走」。群视图「起点已不在这一屏，仍然点得进去」。场所合同里出现「爆炸半径」「寄生期」「guard 强制」 | demo v6 的设计注解被原样移植成产品文案 |
| 2 | **「要你」有五种长相** | 左栏三枚计数 chip；承诺板入口的「1 逾期」；行内的「待裁决 / 待确认 / 待重试」胶囊；会话头「需要你 · 4」加四枚截断的胶囊；卡头「提案 · 拆解 · 待裁决」 | 每个面各自实现信号，没有共用的记号；chip 只给数字，不说是什么 |
| 3 | **没有层级，全是胶囊** | 字号 18 种，其中 10.5px 出现 101 次；圆角 20 多种；padding 134 种取值；约 370 处写死颜色。承诺板一行最多约 18 个元素（`Board.tsx:493-867`）；「无期限」「无信号」这种「没有」也画成彩色胶囊 | 没有字阶和间距体系；颜色被拿去做装饰，不再专属于异常 |
| 4 | **骨架是 IM 客户端** | 左栏 58 个群加 35 个私聊，多数标「未接入」，581 条未读 | 把云之家的会话列表搬了过来，而不是投影图上「要你」的部分 |
| 5 | **内部实现外泄** | 会话头「私聊 · 67f334…-67f334…」、模型名 `grok-4.6`；右栏把 URL 当标题，并且同一条重复四次；群视图把限流错误的原始 JSON 整段贴出；场所合同列出 `yzj_doc_delete` 这类工具名；lease 卡头部露出英文 | 调试期的直出没有收口 |
| 6 | **开口前要读三行** | composer 上方依次是：落点条；语态分段 + ⚡轻问 + @ + 提示句；然后才是输入框。群视图还另有一套 composer（`PlaceView.tsx:855`），两套已经长得不一样 | 「听众可见」被实现成一条常驻说明，而不是一个记号 |
| 7 | **右栏不跟焦点** | 从话题切到群视图，右栏仍挂着上一个话题的 7 个产出；判断面的「记忆」页签永远为空 | 右栏的状态由三处拼起来（frame、预览、会议高亮），没有单一的「焦点」概念 |
| 8 | **不跟宿主主题** | 宿主切到暗色后，工作台仍是亮的；cards 包用的 `--dsh-color-*` 在宿主里根本不存在；`board.module.css` 引用了未定义的 `--line`、`--ink-soft` | token 挂在各栏根节点，没有接宿主的 `body[data-ds-dark-theme]` |

还有几处同根的小病：「返回」有三种写法，板上那个还会丢掉后退历史；⚡ 一个符号表示六种意思；同一组修理动作有三种界面（板的五页签、事件枢纽的复制版、目标页的平铺按钮）；agent 有五种叫法（云小助 / Agent / AI / 🤖 / @next）。

## 3. 界面八律

每条都写明：规则是什么、为什么这样定、对应哪条上位法。原型里每一条都能找到落点。

### 律一 · 界面不解释自己
屏上只出现两样东西：**事实**（谁、什么、何时、在哪）和**动词**。设计理由留在文档里。任何需要读一句论证才敢点的按钮，说明它本身设计错了。规格词一律换成人话（§7）。
*对应上位法：D10 概念分层披露（机制概念埋进默认值）；私账册「产品只说人话」。*

### 律二 · 「要你」只有一种长相，一路点到底
「要你」只有一个记号：**琥珀色实心点 + 动词**（确认 / 验收 / 定 / 签 / 答）。它在信号阶梯的每一级长得一样：

> 左栏「要你」逐条 → 地方行上的点 → 会话头下方的一行指针 → 卡片标签

每一级点下去，都落到下一级，最终落在卡上并闪一下。
*对应上位法：D13⑦ 信号即门、逐级兑付；收件箱是唯一的跨会话聚合处；决断条只指路、不复制、一行封顶。*

### 律三 · 静为常态，色为例外
底色是中性灰阶。颜色只表达两件事：

- **听众**：蓝 = 别人听得见；纸色 = 只有你和云小助。
- **异常**：琥珀 = 要你；红 = 逾期或失败；绿 = 刚做完。

「运行中」不是异常，用转圈表示，不用颜色。「没有」不画：没期限就不显示期限，没信号就不显示信号。没接入的群收成一行「51 个群未接入 ›」，未读数只给接入的地方。
*对应上位法：A6 v4.21「只有状态和异常能用饱和色」；空态三义。*

### 律四 · 听众零成本可见
每个输入框底部都有**一颗听众标签**：🔒「仅你和云小助」（纸色）或 👥「发到群里 · 产品讨论群」（蓝色）。⌘. 切换。**发送键上的字跟着变**：「发给云小助」/「发到群里」/「发给张锐」。在按下去的那一刻，听众被第二次说出来。

私下的话在流里收进一条纸色带，带头写「只有你和云小助」，不再给每条消息挂一个「私」字。
*对应上位法：§1.6 听众集合；检验标准②；D13④ 锚定条的四个问题。落点和可见性由标签回答；受话者由 @ 回答；引用由回复条回答，只在有回复时出现。*

### 律五 · 一行一个信号，动词跟着焦点
列表的每一行静态时只亮**最要紧的一个信号**，优先级是：逾期 › 等你 › 没动静 › 快到期 › 在做 › 正常。动词在悬停时出现在行尾；选中一行时，全套动词出现在右栏。出生故事（原话、谁说的、在哪说的）放进右栏，属于第二级披露。悬停不是唯一通道：右栏和键盘都能到。
*对应上位法：A6 就近动词；出生故事降两级披露、hover 永远不能是唯一通道；#57 修理入口必须是能执行的动词条。*

### 律六 · 右栏跟着焦点走
中栏是流，右栏是**当前焦点的物**：

| 中栏焦点 | 右栏显示 |
|---|---|
| 话题 / 群 / 私聊 | 产出 · 记忆 · 资料 |
| 承诺板或目标页上选中一行 | 这条承诺的来龙去脉，加全套动词 |
| 点了「并排看」 | 预览，宽度加到 500，底部带验收键 |
| 没有焦点 | 收起 |

切走焦点，右栏随之重算，不再挂着上一处的东西。
*对应上位法：D5 中栏是流、右栏是物；#62 对象面账本律：右栏 = f(会话, tab)；切会话即收。*

### 律七 · 摩擦只留在主权时刻，并且是被设计过的
- **验收**：卡上的主按钮是「先并排看」。没看就点「通过」，卡里会长出一行：「你还没打开过这份交付。验收前看一眼？[并排看] [不看，直接通过]」。这是提醒，不是禁止。
- **打回**：就地展开一个原因框，并标明「会以你的名义发给李婷」。不再用 `window.prompt`。
- **作废**：两段式。
- **催**：云小助拟稿，你改成自己的话再亲自发出。

非主权的动作（切换、展开、过滤）一律零摩擦，并且可撤销。
*对应上位法：摩擦四分法与摩擦检验句；#57 作废两段式；B4 催办 = 拟稿 + 亲发；验收的原生姿势是并排预览。*

### 律八 · 键盘一路到底；桌面按 1 = 手机回 1
`⌘K` 到任何地方；`J` / `K` 换下一个；数字键回答当前卡；`⏎` 打开；`Esc` 返回到你离开时的位置。卡上选项的编号，和云之家 DM 兜底里「回 1 / 2」的编号是同一套，每张卡底部也写着「云之家里回 1 / 2 也行」。
*对应上位法：§0 检验标准③ 动词 × 投影完备矩阵。*

## 4. 信息架构

### 4.1 三栏各管一个问题

宿主的几何不变：左栏 264–420（默认 280），中栏 ≥ 640，右栏 300–520（默认 360），三栏都归宿主。

| 栏 | 回答的问题 | 内容 |
|---|---|---|
| 左 | **去哪？** | 要你 › 运行中 › 承诺 › 地方（云之家 / 本地） |
| 中 | **做事** | 一条流（话题 / 群 / 私聊），或一本账（承诺 / 目标 / 我定过的） |
| 右 | **看物** | 焦点的物、来龙去脉、预览 |

### 4.2 左栏（`sidebar.workspaces` 区域；宿主的 logo、新会话、设置不动）

```
⌕ 跳到…                     ⌘K
要你                          3
 ● 确认  写入 12 条到竞品对比表
         产品讨论群 · 5 分钟
 ● 验收  Q3 复盘材料初稿
         李婷 · 昨天
 ● 定    9 月对账 3 处差异
         财务群 · 昨天
运行中                        1
 ◌ Q4 路线图整理
   产品讨论群 · 第 3 步，共 4 步
☰ 承诺                    1 逾期
云之家
 # 产品讨论群                  ●
   ├ 竞品对比表               ●       ← 只列有事的话题
   └ Q4 路线图整理            ◌
 # 财务群                      ●
 (婷) 李婷                     ●
 (锐) 张锐
 # 设计评审群                  2
 # 51 个群未接入 ›
本地
 ▢ dsh-yzj
```

- 「要你」从三枚计数换成**逐条指针**，每条写清动词、对象、地方、多久了。它仍然是收件箱的注意力段，只指路，点下去落在卡上。超过 5 条时折叠成「还有 N 条 ›」。条目变多本身就是审批疲劳的信号，届时卡上会提议「以后这类不用问」。
- 清零时显示「✓ 都处理完了」。这是空态的样本。
- 话题子行只列有事的（要你或在做的）和当前打开的。办完的话题回到群视图里。

### 4.3 中栏视图

| 视图 | 进入方式 | 头部 |
|---|---|---|
| 话题 | 左栏子行、群视图里的话题卡、⌘K | `‹ 来处 │ 产品讨论群 / 竞品对比表`；右侧是「● 云小助在岗」和 ⋯ 菜单 |
| 群 | 左栏地方行、话题头的群名 | `# 产品讨论群 · 12 人 · 2 个话题` |
| 私聊 | 左栏人名 | `(婷) 李婷 · 私聊` |
| 承诺 | 左栏「承诺」 | 一组四透镜：全部 / 欠我的 / 我欠的 / 🔒我定过的；外加「+ 新目标」 |
| 目标 | 承诺板上的目标标题、来龙去脉里的「挂在」 | `‹ 承诺` |

**导航**：只有一个返回按钮，上面写着要回到哪里（「‹ 承诺」）。`Esc` 等价于它，并恢复当时的滚动位置。「向上」走面包屑（话题头的群名）。⋯ 菜单里收着低频操作：云小助在这里的规则、完整过程、在云之家打开、转交这个话题、另起一个话题。

### 4.4 「不增加入口」自检

| 新出现的东西 | 为什么不算新入口 |
|---|---|
| ⌘K | 到已有地方的捷径，自己不是一个地方 |
| 左栏「要你」逐条 | 还是收件箱的注意力段，只是从计数换成了指针 |
| 🔒我定过的 | 承诺板的第四个透镜，即上位法里的「第三取景框」 |
| 右栏「来龙去脉」 | 对象面在承诺行上的投影 |

## 5. 逐面设计

### 5.1 会话流

- **消息**：头像 28px，名字加时间一行，正文 14px，不用气泡。人和 agent 用同一种行。
- **私语带**：连续的私下内容（你对云小助说的、它的回话、它的工作步骤、只给你看的卡）收进一条纸色带，左侧有一道 3px 的纸色轨，带头写「🔒 只有你和云小助」。公开内容不加任何装饰。
- **工作步骤**：收成一行「✦ 云小助做了 4 步 · 38 秒 ›」。展开后用人话写每一步（「汇总三家公开资料」），工具名用等宽小字靠右（`web.search ×6`），最后一行是「看完整过程 ›」。在做的那一组默认展开，标题写「云小助在做 · 第 3 步，共 4 步」。
- **登记回执**：云小助从一句话里记下了承诺，就在那句话下面挂一行「✓ 记下了：张锐负责 · 价格页数据 · 周二前 [改]」。推断要亮出来，并且可以就地纠正。
- **话题卡**（群视图里）：一行，带地方、条数、一个信号（要你确认 / 云小助在做 / 办完了）。

### 5.2 卡：一套语法

所有可应答对象共用一个骨架：

```
● 要你确认                              🔒 只有你看得到
写入 12 条记录到「竞品对比 · 评审表」              ← 标题：16px 600
写操作。产品讨论群的规则：写表格前每次都问你。         ← 为什么问你：一句
┌ 工作区  产品组                    ┐
│ 表格    竞品对比 · 评审表（新建）   │            ← 要件：2–4 行
└ 写入    12 条 · Notion 4 / …      ┘
[1 确认写入] [2 先不写]  看参数        云之家里回 1 / 2 也行
```

六种交互模式都落在这个骨架上：

| 模式 | 卡 | 底部 |
|---|---|---|
| 单答确认 | 写确认、移交确认 | `[1 主动作] [2 不]` |
| 逐条裁决 | 拆解提案、对账差异、发现 | 每条一排选项胶囊（数字键选，J/K 换条），底部「定下这 N 处」；选满才能提交 |
| 双动词验收 | 任务交付、承诺交付 | 「先并排看」→ `[1 通过验收] [2 打回…]`；没看就通过会多问一句 |
| 签发 | 立目标、租约 | `[1 签发] [2 先不签]`，要件里亮出边界 |
| 多出口评估 | 差距简报 | 每条：已达成 / 部分 / 缺失；底部「验收」或「继续」 |
| 待答询问 | agent 问你一句 | 选项 + 一个「直接回一句」输入框 |

- **答完的卡**收成一行吸收态：「✓ 你确认了写入 · 12 条进了「竞品对比 · 评审表」 刚刚」。四种被吸收（已被取代、已移交、已作废、已合并）也用这一行，只换开头的动词。
- **负重档**（有外溢风险）不再用「按两次」。主按钮旁边加一行琥珀色的「会影响：…」，按钮本身不变。

### 5.3 Composer

```
┌─────────────────────────────────────────────────────────┐
│ ✦ 云小助拟的稿 · 改成你的话再发                        ×   │  ← 只在催 / 拟稿时出现
│ ↩ 回复 张锐：「价格页的数据我来补…」                   ×   │  ← 只在回复时出现
│ 张锐，价格页数据今天能给吗？…                              │
│ [👥 发给张锐 ⌄]  @  ⚡快问           张锐能看见  [发给张锐 ⏎] │
└─────────────────────────────────────────────────────────┘
```

- **听众标签**有三个选项：仅你和云小助 / 发到群里 · <地方> / 只问不办（快问：只读、不开任务）。整个输入框跟着变色：纸色、蓝色描边、虚线。
- 公开语态下，右侧写一句「12 人能看见，以你的名义」。
- **群视图和话题共用这一个组件**：群视图固定为公开，标签不可切换。
- `⏎` 发送，`⇧⏎` 换行，`⌘.` 切换听众，`Esc` 失焦；输入法组字时的回车不触发发送（沿用现状）。
- 押、以后… 这些句式的拦截逻辑不变（`privateSay`），只是拦下之后的回显改成私语带里的一行。

### 5.4 承诺（对账面）

- **四个透镜，就是四种组织轴**，不再有两组都带「全部」的分段：
  - 全部：按目标分组，后面是「没挂目标」和「你答应别人的」；
  - 欠我的：按人分组，目标降为行内的一个小标签；
  - 我欠的：按对方分组；
  - 🔒我定过的：纸色页，就是私账。
- **今天条**：`[1 逾期] [3 等你] [1 没动静] [📅 明天 14:00 竞品评审会 · 材料 2/3 就绪 ›]`。数字是门，点了落到对应的行。
- **行**：`头像 │ 标题 / 谁 · 哪 │ 一个信号`。悬停时信号换成动词（催 · 去看）；「等你」的行，动词就是「去确认 / 去验收」。
- **组内排序**是对账排列：逾期 › 等你 › 没动静 › 快到期 › 在做 › 正常；已完成的折成「已完成 N ⌄」。
- **选中一行**，右栏显示来龙去脉：
  - 怎么来的：原话引用，加谁、何时、在哪，和「记错了？改」；
  - 之后：时间线；
  - 挂在：目标和地方，都能点；
  - 动词：`[催张锐] [顺延] [转给别人] [合并] [作废…]`。全站只有这一组修理动词，事件枢纽和目标页复用同一个组件。
- 板上合法的增量仍然只有三样：对账排列、一跳指路、就近动词。不做拖拽、百分比、自建视图（v4.21）。

### 5.5 目标页

自上而下：

1. 眉行：`◎ 目标 · 你负责 · 罗总验收`；
2. 标题，24px；
3. 完成标准，放在一块浅底框里；
4. 一行事实：截止 · 在跟 · 逾期 · 最近动静 · 在云之家打开 ↗；
5. **至多一条**提示，例如「完成标准上周改过，上次评估还是按旧标准做的 [按新标准重新评估]」；
6. `[交给…] [拆解] [评估进度]`；
7. 要你（只放指针）· 执行 · 产出。

删掉三段说明文字和「闭环自检」。

### 5.6 我定过的（私账层）

整页纸色。顶部一行：「🔒 只有你看得到。不进公司的账，随时可以整本带走。」

按裁决类别分组，每组一句话讲清比值的原料，例如「验收 · 33 次：没有一次被推翻 · 平均 22 小时后才去验」，下面挂押注和规矩行。

零新场所、三不入、无分数律都不变。「判例册 / 销毁整本账」移进 ⋯ 菜单。

### 5.7 群规则（原「场所合同」）

从 ⋯ 菜单或「● 云小助在岗」进入。用人话分六行：

- 接谁的话
- 每次都先问你
- 写之前问一次
- 不会做
- 你给过的授权
- 它记着的

工具名收进「看明细」里，以等宽小字列出。「向群发在岗声明」「移出服务」这类操作保留，放在对应的那一行。

### 5.8 空态、错误、载入

- **空态都给样本**：例如右栏「这里还没有产出」下面放一个虚线框，「云小助写的文档、建的表格，和群里发的文件，会出现在这里——点一下就能并排看。」（空状态样本律）
- **错误说人话，并自动恢复**：「云之家暂时限流，30 秒后自动重试 · 下面是上次读到的内容」。原始错误收进「详情」。
- **载入**用骨架行，不用转圈占满一屏。轮询节奏统一为一个刷新器：有人看的面 5 秒，后台 30 秒。
