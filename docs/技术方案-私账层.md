## 0. 一句话与总判据

**组织图记着你每一次签发的裁决与后来的事实；私账层只是把两者对上，摆给你看，让你自己写一句"以后这类事……"。**

四动作 = 押 / 校准回执 / 归因 / 换挡；**换挡是唯一产出**（软合同私账句），其余是仪器。零新场所：私账住裁决 turn 的私语道、到达经晨报（opt-in）、汇总经第三取景框「我的判断」、换挡经合同面板软区。

总判据（§10 有断言形态）：
1. **零新场所**：无私语通道会话、无金库页、无 DM 副本、无 IM 消息——三不入与对象面账本律由构造满足，不靠 filter；
2. **人发起**：押/归因/换挡全部是人在既有面上的动词；**系统不邀约**（无 invite 族、无判据谱、无配额）；
3. **托管律**：pgraph 第二存储域宪法三条不变（viewer 单态／审计不挂源／本人可取走销毁）；单向引用（组织图 schema 无私账字段）不变；
4. **产婆术/持镜人**：模型无 text 参数、agent 只读私账且仅人发起时刻、显示规则由人签发；
5. **无分数**：取景框组头只返回原料计数与停留（返回类型无 string 判词），比值由人得；
6. **比例尺**：法条与代码同受预算；每轮 review 点名删除项。

## 3. 词汇表（私账标注族三型 + 补登 + 软合同句——只存在于 pgraph）

```ts
/* —— 预期（押）—— */
'expectation/opened'     // { text（原话直存——出站侧从人的私语原文截取，模型无此参数）,
                         //   verdict: AnchoredText（锚到最近一条人签发裁决边——推断，ack 亮出可纠）,
                         //   family（裁决族 §4.0）, checkpoint: { text, ts? }
                         //   （取值序：还没开的那场会【事件枢纽服务边】› 未来的 due › 无戳不参与时间轮；v3.1 删 source 枚举——text 已说明来源）,
                         //   idemKey = verdictRef }   // 同一裁决至多一次；withdrawn 后再 opened 幂等 no-op（不可再押）
'expectation/withdrawn'  // { reason }——唯一退出动词，留痕不删史；无 updated（不可改笔 = 改笔通道不存在）

/* —— 补登事实（图外事实唯一入口）—— */
'fact/noted'             // { text（原话直存）, about: verdictRef | expectationId, anchor?（私语话语锚） }

/* —— 校准回执 —— */
'calibration/opened'     // { verdictRef, family,
                         //   type: 'pledged' | 'reversed' | 'vindicated'   —— 三处出生，由比值分子定义（§4.2）
                         //   then: AnchoredText[]（"你当时"栏：裁决事实快照 + 押过的原话 + 当时在档的证据条目）,
                         //   later: AnchoredText[]（"后来"栏：事实快照；pledged 到检验点而无事实时为空，等补登追加）,
                         //   factRef: OrgAnchor | FactNotedRef | { kind:'checkpoint', ts },
                         //   idemKey = (verdictRef, factRef) }   // 一份事实至多一执，配 seq 最近的那次裁决
'calibration/answered'   // { attribution: 'q1'|'q2'|'q3'|'q4' }——人按；可改 = 追加最新生效
'calibration/dismissed'  // 「配对错了」：判例不入任何派生；纠回 = 之后再 answered 即覆盖（更正即追加——v3.1 删 reopened 型）
'calibration/seen'       // v3.1：私账显示层事实——该回执的私条或取景框行**首次在屏**（仅记一次；归因率分母；默认无到达信号下不记此项则"没看见"与"不在乎"不可分）
'calibration/appended'   // { later: AnchoredText }——补登事实追加到既有回执的"后来"栏（pledged 型的补登路径，不出第二执）

/* —— 换挡 = 软合同私账句（本层唯一产出）—— */
'clause/set'             // { key: 'spread'|'mirror'|'morning'|'lease'（P1 三句 + 租约出口私记；> 5 句押面板门）, family?, text（原话）, leaseRef?（key='lease' 时：组织侧 lease/granted 锚——私账私记，组织图零字段） }
'clause/cleared'         // { key, family? }
                         // 回喂事件数 = count(set) + count(cleared)（含 lease）——dogfood 裁决指标的直接观测；30 天末生效句数 = 派生
```

**删除的族**：`invite/*`（邀约/立约时窗/疲劳）、`gear/*`（三档位）、`mirror/*`（族级开关）、`presence`（那是 #63 组织侧的族，与私账无关，此处只作澄清）。判例 = `calibration/answered` 留痕；结清 = 派生（answered 存在即结清，v3.1 删 settled 型）；组头原料 = 纯派生滚动查询（近 90 天，零存储）。**零新族、字段级收缩**。

**原话直存律**：`expectation.text` / `fact/noted.text` / `clause.text` 由 surface 出站拦截从人的私语原文截取注入；**模型工具面无任何写入私账的工具**（v2 的 `pledger_register` 删除）——产婆术在参数面上成为"通道不存在"。

## 4. 四动作的工程规格

### 4.0 裁决族（组织轴）

从 `verdict-settled.kind` 派生，P1 六族：**验收**（验收卡 accept/reject）/ **标准写确认**（确认卡 approve/deny）/ **对账裁决**（裁决卡 itemDecided）/ **委派**（登记签发）/ **目标提案**（proposal itemDecided，含拆解提案）/ **交付推断**（dlvinfer 确认/不是交付）；授权租约族随组织侧开门。每条裁决记 `{ family, agree: boolean（同意提案 / 偏离提案——偏离 = reject/deny/驳回/不是交付/修改后签发）, dwellMs?（停留——本人行为事实，仅入私账）, waitMs?（**等你多久**：裁决卡 openedAt→decidedAt，接缝① payload 携两时间戳、写入时快照——组织付的摩擦，分母第二个数，v3.1） }`。

### 4.1 押

- **入口**：私语道 composer 出站拦截 `^(押|/押)[：:\s]+(.+)$`（surface 桌面出站分诊既有点；**不经 agent turn**）；**发现路 = 裁决签发后本会话私语道 placeholder 文字**「……或「押：」一句预期，可选」——仅当本会话最近裁决尚未押过时显示（占位文字不是邀约：不弹卡、不计数、不重复）。
- **锚**：同会话最近一条人签发裁决边（`verdict-settled` 序）；无 → 私语回"还没有可以押的裁决"（不猜不问）；已押 → 回"这条裁决已经押过了。要改，先撤回——撤回之后，这条就不能再押"。ack 亮出锚与检验点可纠（"押已记：锚到你 10:04 的验收《评审表》；明早评审之后结果会回到那张卡下面"）。引用指名押（quote 某卡后说押）押 P1.5。
- **检验点**：事件（该会话对象面 events[0]，服务边）› due（该承诺 due.ts）› 无戳；有戳者入时间轮。
- **余生/死亡**：锚死（裁决对象 voided/transferred/墓碑）→ `premiseState:'changed'` 派生态（**零事件**）→ 取景框行显形「前提已变」双出口（撤回 / 照旧对）；撤回留理由；同一裁决不可再押（幂等锚吸收）。
- **删**：邀约卡、判据谱、日配额、疲劳治理、立约时窗（无邀约即无窗——不可回填由"只锚最近裁决 + 幂等锚"保证）。

### 4.2 校准回执（三处出生，回流配对表）

**出生由比值分子定义**：只有能为"人相对提案的增量信息"提供证据的事实才出执；盖章后平安无事不出执。三型：

| type | 出生条件 | "后来"栏来源 |
|---|---|---|
| `pledged` | 押过的裁决：检验点到达（时间轮）**或**事实回流——先到者开执 | 按族的结构事实（v3.1 明标）：验收 → 配对表两列任一；**委派 → 该承诺终态（closed cause）或检验点时逾期信号**；目标提案 → 该目标终态；标准写确认/对账/交付推断 → 配对表反转列；皆无则空，等 `calibration/appended`（补登） |
| `reversed` | 同意提案（agree=true）而现实反转 | 回流配对表"反转"列的事实快照 |
| `vindicated` | 偏离提案（agree=false）而现实印证 | 回流配对表"印证"列的事实快照 |

**回流配对表（P1；它只配对事实、不向人开口——是表不是法；行随 dogfood 增删）**：

| 裁决族 | 反转（同意后被推翻） | 印证（偏离后被证实） |
|---|---|---|
| 验收 accept / reject | accept 后：同承诺义务线 7 日内出现血缘回指的新一轮 `commitment/opened`（转包子边强路径 / 同 goalRef 同会话弱路径）、`commitment/reopened`、差距简报把该交付标为未达 | reject 后：返工轮次 +1 的交付被 accept（打回有内容）；或差距简报把打回项标为已达 |
| 标准写确认 approve / deny | approve 后：写入结果被 `tombstone/appended`（回滚）| **无结构性回流**——正面证据只能靠押（如实明标） |
| 对账裁决 确认 / 驳回 | 确认项写入后被墓碑/更正 | 驳回项随后 `receipt/recorded{kind:'external'}` 携原因回指该 finding（供应商回函类） |
| 委派 签发 | 7 日内拒领（REJECTED 回流）或 voided | 无 |
| 目标提案 确认 / 驳回 | 确认落库的目标/子承诺 7 日内 voided | 无 |
| 交付推断 确认 / 不是交付 | 确认后回执被纠正（验收卡级联作废） | 无 |

**幂等**：(verdictRef, factRef)；`pledged` 型检验点先到时 factRef = checkpoint 伪边，后到的真实事实走 `appended` 追加而非第二执。**"当时"栏只陈列裁决事实快照**（"你在 8/30 10:30 验收了《评审表》"+ 押的原话 + 当时在档的简报条目）——不写"隐式预期即它已够好"之类推演（两输入联合类型：有押 / 无押，第三种输入不可构造）。**两栏照片**：`then[]` / `later[]` 全部 AnchoredText，出生时从图拍下原文；渲染入参无组织图 service（断组织图零缺字）。

**住址**：私条 = `pledgerStripFor` 在**裁决卡所在会话私语道**渲染（原卡下方，仅操作者桌面）；**无私语道的裁决**（枢纽/板 CTA 签发——话语 turn 落操作者私语域无卡）→ 回执只在取景框，**不挂组织侧取景框行**。会话归档不复活侧栏。**到达**：默认无信号；opt-in 晨报行（§5）。**余生**：未答不老化不可催不成欠账。**死亡**：「配对错了」dismissed，可纠回。

**删**：沉降区、折叠归并条、静默沉降律实现、私语通道会话、自聊 DM 副本。

### 4.3 归因

私条上四格 + 「这不是那件事的结果」（第五出口）；候选注 = **静态常量表**（"你当时看到的，就是后来发生的" / "结果是好的，但不是因为你当时看到的那些" / "「X」当时就在卡上" / "后来的事，当时看不到"），第三格的引用从 `then[1].t` 取快照标题；**无模型通路、无判词**。可改 = answered 追加。分布镜删除（判例 > 20 押门）。

### 4.4 换挡（软合同私账句）

- **P1 三句**（key）：`spread`「以后验收前，先把要求和交付摆给我看」/ `mirror`「以后验收前，给我看我上次在这类事上的结果」/ `morning`「每天早上告诉我有几条结果等着看」；P1 族限**验收**（其余族回"这类还没接上"）。
- **三入口**：私语道说一句（出站拦截 `^(不再|取消)?\s*(以后|每天早上)(.+)$` + 关键词归类：摆开证据/不预选/先看证据→spread；判例/看我的/上次→mirror；晨报/每天早上/几条→morning；不认得→列出三句，**不猜**）；合同面板软区（删）；私条与组头就近动词「以后这类事…」**就地展开：第一行先摆本族 2×2 + 两分母（先看比值再换挡——v3.1，防从一条回执出发的可得性偏差），其下三句 + 「不用再问我」+「先不改」**（不跳转）。「不用再问我」= 租约出口 → **传送门到组织侧 `lease/granted` 强确认卡**（v3.1：最小租约随 D4 同批开工——对象级 + 期间级 + 强确认 + 到期收回 + guard 命中放行，§5.1 既有；签发成功后 pledger 经只读订阅观测本 turn 的 lease/granted 私记 `clause/set{key:'lease'}`；**P1 分配必须两个方向都可达**——否则 30 天 dogfood 只能观察加摩擦，实验无效）。
- **生效面**：`spread` → 验收卡渲染前置「先看」私条：要求（目标成功标准逐条 × 交付里有/没有；无目标则对方原话 + 委派原话）× 交付（工件 + 返工轮次 + 交付主张原话）——既有负重档实现收编为此形态（不预选/不截断）；`mirror` → 验收卡下「上次」私条：同族已归因判例 ≤2 条，每条一跳回取景框证据面；`morning` → 晨报行（§5）。全部受 D10。
- **回喂事件 = clause 写入/删除次数**，dogfood 裁决指标。
- **删**：换挡台、三档位 UI、按族档位表、`gear/*`、`mirror/*` 族级开关与例数、就地合环注册表、入口不垄断校验。

## 7. 治理
