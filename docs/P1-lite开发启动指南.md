## 2. 铁律（违反任何一条 = 返工）

1. **不改、不删、不 import `packages/*` 旧代码**（旧系统拆弹是另一个独立任务）。新代码全部在 `next/`（scope `@yzj-next/*`）。
2. **绝不向 DSH session 日志 append 任何自定义事件类型**（白名单硬约束，旧系统踩过雷）。产品级事实只进图日志。
3. **图查询一律带 viewer，且由编排层按 turn 绑定，不作为模型工具参数**；audience×viewer 桥接按技术设计 §3.3。
4. **按附录 A 顺序施工**：段 0-5 连续推进（内含两个 Bruce 评审停点）；段 6-14 的每一段**开工前与 Bruce 确认**（它们多依赖基建/凭据/证据就绪）——但写代码时的接口与数据形态永远按完整设计，不做"临时形态"。
5. 段 0（事实验证）未过不进段 1。
6. 每个模块带测试交付（旧测试用例是移植基线）；每段结束 `pnpm test` 全绿 + 对应验收脚本。
7. 部署走**双实例**（独立 `DSH_HOME=~/.dsh-next` + 独立端口；allow-list={两个测试群+自聊}）。绝不把新 bundle 装进现有 web profile。
